# sulfone.argon

Argon is the web-based user interface for browsing, searching, and managing CyanPrint templates. It provides a visual interface to the Zinc registry.

## Repository

[github.com/AtomiCloud/sulfone.argon](https://github.com/AtomiCloud/sulfone.argon)

## Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| TypeScript | Primary language |
| Svelte | UI framework |
| SvelteKit | Full-stack framework |
| Tailwind CSS | Styling |
| swagger-typescript-api | Type-safe HTTP client (generated) |

## Key Files

| Path | Description |
| ---- | ----------- |
| `src/routes/` | SvelteKit routing pages |
| `src/lib/components/` | Svelte components |
| `src/lib/` | Utilities and helpers |
| `src/hooks.server.ts` | Server hooks (authentication) |
| `src/config/` | Configuration files |

## Features

### Template Browsing

- Grid and list views of templates
- Category-based navigation
- Advanced search with filters
- Template preview and documentation

### User Management

- Descope OIDC authentication
- User profiles
- Template ownership and permissions

### Template Management

- Create and publish templates
- Version management

## Page Structure

```
/                         # Home page with featured templates
/templates                # Browse all templates
/templates/[user_id]/[template_id]  # Template details
/registry                 # Search templates (with search functionality)
/profile                  # User profile
/plugins/                 # Plugins management
/processors/              # Processors management
/resolvers/               # Resolvers management
/tokens/                  # Token management
/register/                # Registration page
```

## Building

```bash -c
# Install dependencies
bun install

# Development server
bun run dev

# Build for production
bun run build

# Run tests
bun run test

# Type checking
bun run check
```

## Configuration

```env .env -c
# .env
DESCOPE_ID=your-descope-project-id
DESCOPE_SECRET=your-descope-secret
AUTH_SECRET=your-auth-secret
PUBLIC_LANDSCAPE=lapras  # Options: pichu, pikachu, raichu, lapras (default: lapras)
```

## Key Components

### Template Card

Displays template information in a card format:

import { Callout } from 'fumadocs-ui/components/callout';

<Callout type="info">
Most fields in the template object are optional.
</Callout>

```svelte
<TemplateCard
  template={{
    name: "react-app",
    description: "React application template",
    userId: "user-123",  // optional
    email: "user@example.com",  // optional
    tags: ["react", "typescript"]  // optional
  }}
/>
```

### Search

Full-text search with autocomplete on the registry page (simplified example):

```svelte
<input
  type="text"
  placeholder="Search templates..."
  bind:value={searchTerm}
/>
```
