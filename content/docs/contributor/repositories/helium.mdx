# sulfone.helium

Helium provides SDKs for developing CyanPrint templates, processors, plugins, and resolvers. It supports multiple programming languages with consistent APIs based on an inquirer pattern.

## Repository

[github.com/AtomiCloud/sulfone.helium](https://github.com/AtomiCloud/sulfone.helium)

## Tech Stack

| Language | Package | Purpose |
| -------- | ------- | ------- |
| TypeScript | `@atomicloud/cyan-sdk` | TypeScript/JavaScript templates, processors, plugins, resolvers |
| Python | `cyanprintsdk` | Python templates, processors, plugins, resolvers |
| C# | `AtomiCloud.CyanPrint` | .NET templates, processors, plugins, resolvers |

## Core Concepts

### IInquirer Interface

All SDKs use an inquirer pattern for collecting user input. The `IInquirer` interface provides methods for asking questions:

| Method | Description | Returns |
| ------ | ----------- | ------- |
| `text` | Text input | `string` |
| `confirm` | Yes/no confirmation | `boolean` |
| `select` | Single selection from options | `string` |
| `checkbox` | Multiple selections from options | `string[]` |
| `password` | Hidden text input | `string` |
| `dateSelect` | Date picker | `string` or `DateOnly` |

### IDeterminism Interface

The `IDeterminism` interface provides a `get()` method for generating deterministic values based on input keys. This ensures consistent output for the same inputs across template runs.

### Cyan Output Structure

Templates return a `Cyan` object that defines how files should be processed:

```typescript
interface Cyan {
  processors: CyanProcessor[];
  plugins: CyanPlugin[];
}
```

### Basic Template Usage

```typescript
import {
  StartTemplateWithLambda,
  type IInquirer,
  type IDeterminism,
  type Cyan,
  GlobType,
} from '@atomicloud/cyan-sdk';

StartTemplateWithLambda(async (i: IInquirer, d: IDeterminism): Promise<Cyan> => {
  // Ask questions using the inquirer
  const projectName = await i.text('Name of the project?', 'project-name');
  const includeTests = await i.confirm('Include test files?', 'include-tests');

  // Use determinism for consistent values
  const id = d.get('unique-id');

  // Return the Cyan configuration
  return {
    processors: [
      {
        name: 'my-processor',
        files: [
          {
            glob: '**/*',
            exclude: [],
            type: GlobType.Template,
          },
        ],
        config: { projectName, includeTests, id },
      },
    ],
    plugins: [],
  };
});
```

### Basic Template Usage

```python
from cyanprintsdk.main import start_template_with_fn
from cyanprintsdk.domain.core.inquirer import IInquirer
from cyanprintsdk.domain.core.deterministic import IDeterminism
from cyanprintsdk.domain.core.cyan import Cyan, CyanProcessor, CyanGlob, GlobType

async def my_template(i: IInquirer, d: IDeterminism) -> Cyan:
    # Ask questions using the inquirer
    project_name = await i.text("Name of the project?", "project-name")
    include_tests = await i.confirm("Include test files?", "include-tests")

    # Use determinism for consistent values
    unique_id = d.get("unique-id")

    # Return the Cyan configuration
    return Cyan(
        processors=[
            CyanProcessor(
                name="my-processor",
                files=[
                    CyanGlob(
                        glob="**/*",
                        exclude=[],
                        type=GlobType.Template,
                    )
                ],
                config={"projectName": project_name, "includeTests": include_tests},
            )
        ],
        plugins=[],
    )

start_template_with_fn(my_template)
```

## C# SDK

### Installation

```bash
dotnet add package AtomiCloud.CyanPrint
```

### Basic Template Usage

```csharp
using sulfone_helium;
using sulfone_helium.Domain.Core;
using sulfone_helium.Domain.Core.Cyan;

CyanEngine.StartTemplate(args, async (IInquirer i, IDeterminism d) =>
{
    // Ask questions using the inquirer
    var projectName = await i.Text("Name of the project?", "project-name");
    var includeTests = await i.Confirm("Include test files?", "include-tests");

    // Use determinism for consistent values
    var uniqueId = d.Get("unique-id");

    // Return the Cyan configuration
    return new Cyan
    {
        Processors = new List<CyanProcessor>
        {
            new CyanProcessor
            {
                Name = "my-processor",
                Files = new List<CyanGlob>
                {
                    new CyanGlob
                    {
                        Glob = "**/*",
                        Exclude = new List<string>(),
                        Type = GlobType.Template,
                    }
                },
                Config = new { projectName, includeTests, uniqueId }
            }
        },
        Plugins = new List<CyanPlugin>()
    };
});
```

## Contributing

When contributing to Helium:

1. Maintain API consistency across all languages (TypeScript, Python, C#)
2. Update all SDKs when adding new features
3. Follow the inquirer/determinism pattern for templates
4. Write integration tests for new functionality
5. Update documentation for all language variants
