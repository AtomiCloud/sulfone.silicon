# sulfone.helium

Helium provides SDKs for developing CyanPrint templates, processors, and plugins. It supports multiple programming languages with consistent APIs.

## Repository

[github.com/AtomiCloud/sulfone.helium](https://github.com/AtomiCloud/sulfone.helium)

## Tech Stack

| Language | Package | Purpose |
| -------- | ------- | ------- |
| TypeScript | `@cyanprint/sdk` | TypeScript/JavaScript templates |
| Python | `cyanprint-sdk` | Python templates |
| C# | `CyanPrint.SDK` | .NET templates |

## Repository Structure

```
sulfone.helium/
├── packages/
│   ├── typescript/     # TypeScript SDK
│   ├── python/         # Python SDK
│   └── dotnet/         # C# SDK
├── protocols/          # Shared protocol definitions
└── examples/           # Example templates
```

## TypeScript SDK

### Installation

```bash
bun add @cyanprint/sdk
# or
npm install @cyanprint/sdk
```

### Basic Usage

```typescript
import { defineTemplate, input, output } from '@cyanprint/sdk';

export default defineTemplate({
  name: 'my-template',
  version: '1.0.0',

  inputs: {
    projectName: input.string({
      description: 'Name of the project',
      required: true,
    }),
    includeTests: input.boolean({
      description: 'Include test files',
      default: false,
    }),
  },

  async generate({ inputs, fs }) {
    await fs.write(
      'README.md',
      `# ${inputs.projectName}\n\nGenerated by CyanPrint.`
    );

    if (inputs.includeTests) {
      await fs.write('test.spec.ts', '// Add your tests here');
    }
  },
});
```

### Input Types

```typescript
// String input
input.string({ description: 'Project name' })

// Boolean input
input.boolean({ default: false })

// Number input
input.number({ min: 1, max: 100 })

// Select input
input.select({ options: ['typescript', 'javascript'] })

// Array input
input.array({ items: input.string() })

// Object input
input.object({
  properties: {
    name: input.string(),
    version: input.string(),
  }
})
```

## Python SDK

### Installation

```bash
pip install cyanprint-sdk
```

### Basic Usage

```python
from cyanprint import Template, Input, Output

class MyTemplate(Template):
    name = "my-template"
    version = "1.0.0"

    inputs = {
        "project_name": Input.string(description="Name of the project"),
        "include_tests": Input.boolean(default=False),
    }

    async def generate(self, inputs, fs):
        await fs.write(
            "README.md",
            f"# {inputs.project_name}\n\nGenerated by CyanPrint."
        )
```

## C# SDK

### Installation

```bash
dotnet add package CyanPrint.SDK
```

### Basic Usage

```csharp
using CyanPrint;

public class MyTemplate : Template
{
    public override string Name => "my-template";
    public override string Version => "1.0.0";

    [Input(Description = "Name of the project")]
    public string ProjectName { get; set; }

    [Input(Default = false)]
    public bool IncludeTests { get; set; }

    public override async Task Generate(IFileSystem fs)
    {
        await fs.WriteAsync(
            "README.md",
            $"# {ProjectName}\n\nGenerated by CyanPrint."
        );
    }
}
```

## File System API

All SDKs provide a consistent file system API:

```typescript
// Write a file
await fs.write('path/to/file.txt', 'content');

// Write with binary data
await fs.writeBinary('image.png', buffer);

// Create a directory
await fs.mkdir('src/components');

// Set file permissions
await fs.chmod('script.sh', 0o755);

// Copy from template assets
await fs.copyTemplateAsset('assets/logo.png', 'logo.png');
```

## Building

```bash
# Build all SDKs
bun run build:all

# Build TypeScript only
bun run build:typescript

# Build Python only
bun run build:python

# Build .NET only
dotnet build

# Run tests
bun run test
```
