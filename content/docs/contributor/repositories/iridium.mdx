# sulfone.iridium

The CyanPrint command-line interface (CLI) is the primary way users interact with CyanPrint. It handles project creation, template management, and configuration.

## Repository

[github.com/AtomiCloud/sulfone.iridium](https://github.com/AtomiCloud/sulfone.iridium)

## Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| Rust | Primary language for performance and safety |
| Clap | CLI argument parsing framework |
| Tokio | Async runtime |
| Reqwest | HTTP client for API calls |

## Key Files

| Path | Description |
| ---- | ----------- |
| `src/main.rs` | Application entry point |
| `src/commands/` | CLI command implementations |
| `src/config/` | Configuration management |
| `src/api/` | API client for Zinc registry |
| `src/executor/` | Communication with Boron executor |

## Commands

The CLI provides the following main commands:

```bash
# Initialize a new project from a template
cyan print init <project-name> --template <template-id>

# Update an existing project
cyan print update <project-name>

# List available templates
cyan print search <query>

# Configure CyanPrint
cyan print config set <key> <value>

# Login to the registry
cyan print auth login
```

## Configuration

Iridium stores configuration in `~/.config/cyan-print/config.toml`:

```toml
[registry]
url = "https://registry.cyanprint.dev"

[executor]
url = "https://executor.cyanprint.dev"
timeout = "5m"

[auth]
token_file = "~/.config/cyan-print/auth/token"
```
