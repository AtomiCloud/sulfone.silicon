# sulfone.zinc

Zinc is the registry API that stores template metadata, delegates authentication to Descope, and serves template, plugin, processor, and resolver information to CLI users and the web UI.

## Repository

[github.com/AtomiCloud/sulfone.zinc](https://github.com/AtomiCloud/sulfone.zinc)

## Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| C#/.NET 8 | Primary language and runtime |
| ASP.NET Core with Kestrel | Web framework |
| Entity Framework Core | Database access (PostgreSQL) |
| Descope | Authentication service |

## Key Files

| Path | Description |
| ---- | ----------- |
| `App/Program.cs` | Application entry point |
| `App/Modules/Cyan/API/V1/Controllers/` | REST API routes and handlers |
| `Domain/Model/` | Domain models |
| `App/Modules/Users/API/Auth/` | Authentication (API key, Descope integration) |
| `App/Modules/Cyan/Data/Repositories/` | Database repositories |

## API Endpoints

### Templates

```bash
# Search templates
GET /api/v{version}/template

# Get template by ID
GET /api/v{version}/template/id/{userId}/{templateId}

# Get template by slug
GET /api/v{version}/template/slug/{username}/{name}

# Get template versions
GET /api/v{version}/template/slug/{username}/{templateName}/versions

# Push (create or update) template
POST /api/v{version}/template/push/{username}
```

### Plugins

```bash
# Search plugins
GET /api/v{version}/plugin

# Get plugin by ID
GET /api/v{version}/plugin/id/{userId}/{pluginId}

# Get plugin by slug
GET /api/v{version}/plugin/slug/{username}/{name}

# Get plugin versions
GET /api/v{version}/plugin/slug/{username}/{pluginName}/versions

# Push (create or update) plugin
POST /api/v{version}/plugin/push/{username}
```

### Processors

```bash
# Search processors
GET /api/v{version}/processor

# Get processor by ID
GET /api/v{version}/processor/id/{userId}/{processorId}

# Get processor by slug
GET /api/v{version}/processor/slug/{username}/{name}

# Get processor versions
GET /api/v{version}/processor/slug/{username}/{processorName}/versions

# Push (create or update) processor
POST /api/v{version}/processor/push/{username}
```

### Resolvers

```bash
# Search resolvers
GET /api/v{version}/resolver

# Get resolver by ID
GET /api/v{version}/resolver/id/{userId}/{resolverId}

# Get resolver by slug
GET /api/v{version}/resolver/slug/{username}/{name}

# Get resolver versions
GET /api/v{version}/resolver/slug/{username}/{resolverName}/versions

# Push (create or update) resolver
POST /api/v{version}/resolver/push/{username}
```

### Users

```bash
# Get current user
GET /api/v{version}/user/Me

# Update user
PUT /api/v{version}/user/{id}
```

### Token Management

```bash
# List user tokens
GET /api/v{version}/user/{userId}/tokens

# Create token
POST /api/v{version}/user/{userId}/tokens

# Revoke token
POST /api/v{version}/user/{userId}/tokens/{tokenId}/revoke

# Delete token
DELETE /api/v{version}/user/{userId}/tokens/{tokenId}
```

### Likes (Social Features)

```bash
# Like/unlike templates, plugins, processors, resolvers
POST /api/v{version}/{entityType}/slug/{username}/{name}/like/{likerId}/{like:bool}
```

## Contributing

When contributing to Zinc:

1. Follow RESTful API conventions
2. Validate all inputs with schemas
3. Use Entity Framework Core for database operations
4. Write integration tests for API endpoints
5. Update API documentation for new endpoints
6. Use push endpoints for CI/CD workflows (atomic create-or-update operations)
