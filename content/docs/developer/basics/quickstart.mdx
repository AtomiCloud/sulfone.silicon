# Quickstart

Get started with CyanPrint development in minutes. Choose your path based on what you want to build.

## Prerequisites

Before you begin, ensure you have:

- **Docker** installed and running
- **CyanPrint CLI** installed
- **Node.js 18+** for local development

## Quick Start: Create a Template

The most common starting point is creating a template. Run this command:

```bash -c
cyanprint create cyan/new my-first-template
```

This scaffolds a complete template project using the meta template.
