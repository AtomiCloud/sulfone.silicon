# First Plugin

Plugins extend CyanPrint's capabilities by providing reusable functionality to templates. This tutorial guides you through creating a custom plugin.

**Time estimate**: 20-25 minutes

## What is a Plugin?

A plugin is a CyanPrint artifact that:

1. **Provides functionality** - Helper functions, utilities
2. **Integrates services** - Connect to external APIs
3. **Hooks into lifecycle** - Execute at specific template stages
4. **Shares logic** - Reusable across multiple templates

Common plugin use cases:

- Git operations (initialize, commit, push)
- License generation
- Environment variable management
- Validation utilities
- API integrations

## Create a Simple Plugin

Let's create a plugin that generates license files:

```ts
// src/index.ts
import { ICyanPlugin, PluginContext } from '@atomicloud/helium-sdk';

export default class LicensePlugin implements ICyanPlugin {
  name = 'license-plugin';
  version = '1.0.0';

  private context!: PluginContext;

  async initialize(context: PluginContext): Promise<void> {
    this.context = context;
    this.context.logger.info('License plugin initialized');
  }

  async dispose(): Promise<void> {
    this.context.logger.info('License plugin disposed');
  }

  // Public API - available to templates
  async generate(options: LicenseOptions): Promise<string> {
    const { type, year, holder } = options;
    const licenseYear = year || new Date().getFullYear();

    switch (type) {
      case 'MIT':
        return this.generateMIT(licenseYear, holder);
      case 'Apache-2.0':
        return this.generateApache(licenseYear, holder);
      case 'GPL-3.0':
        return this.generateGPL(licenseYear, holder);
      case 'BSD-3-Clause':
        return this.generateBSD(licenseYear, holder);
      default:
        throw new Error(`Unknown license type: ${type}`);
    }
  }

  // Get list of supported licenses
  getSupportedLicenses(): string[] {
    return ['MIT', 'Apache-2.0', 'GPL-3.0', 'BSD-3-Clause'];
  }

  // Validate license type
  isValidLicense(type: string): boolean {
    return this.getSupportedLicenses().includes(type);
  }

  private generateMIT(year: number, holder: string): string {
    return `MIT License
```

```python
from datetime import datetime
from typing import List, Optional

class LicensePlugin(ICyanPlugin):
    @property
    def name(self) -> str:
        return "license-plugin"

    @property
    def version(self) -> str:
        return "1.0.0"

    def __init__(self):
        self._context = None

    async def initialize(self, context: PluginContext) -> None:
        self._context = context
        self._context.logger.info("License plugin initialized")

    async def dispose(self) -> None:
        self._context.logger.info("License plugin disposed")

    # Public API - available to templates
    async def generate(self, options: dict) -> str:
        license_type = options.get("type")
        year = options.get("year", datetime.now().year)
        holder = options.get("holder")

        generators = {
            "MIT": self._generate_mit,
            "Apache-2.0": self._generate_apache,
            "GPL-3.0": self._generate_gpl,
            "BSD-3-Clause": self._generate_bsd,

            raise ValueError(f"Unknown license type: {license_type}")

        return generators[license_type](year, holder)
```

## Configure the Plugin

Create `cyanprint.json`:

```json
{
  "name": "license-plugin",
  "version": "1.0.0",
  "description": "Generate license files for projects",
  "type": "plugin",
  "entryPoint": "dist/index.js",
  "provides": ["license"]
}
```

### Configuration Fields

| Field | Description | Required |
| ----- | ----------- | -------- |
| `name` | Plugin package name | Yes |
| `version` | Semantic version | Yes |
| `type` | Must be `"plugin"` | Yes |
| `entryPoint` | Path to compiled plugin | Yes |
| `provides` | List of provided capabilities | No |
| `hooks` | Lifecycle hooks to subscribe | No |

```ts
import { Cyan, ICyanTemplate } from '@atomicloud/helium-sdk';

export default class MyTemplate implements ICyanTemplate {
  async execute(cyan: Cyan): Promise<void> {
    // Get plugin
    const licensePlugin = cyan.plugins.get<LicensePlugin>('license-plugin');

    // Ask user for license type
    const licenseType = await cyan.inquirer.select({
      message: 'Choose a license:',
      options: licensePlugin.getSupportedLicenses()
    });

    // Generate license
    const licenseContent = await licensePlugin.generate({
      type: licenseType,
      holder: cyan.answers.author
    });

    // Write to output
    await cyan.files.write('LICENSE', licenseContent);
  }
}
```

## Lifecycle Hooks

Plugins can subscribe to template lifecycle events:

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
export default class AuditPlugin implements ICyanPlugin {
  name = 'audit-plugin';
  version = '1.0.0';

  async initialize(context: PluginContext): Promise<void> {
    // Register hooks
    context.hooks.beforeExecute(this.onBeforeExecute.bind(this));
    context.hooks.afterExecute(this.onAfterExecute.bind(this));
    context.hooks.onError(this.onError.bind(this));
  }

  private async onBeforeExecute(event: BeforeExecuteEvent): Promise<void> {
    console.log(`Template ${event.templateName} starting...`);
  }

  private async onAfterExecute(event: AfterExecuteEvent): Promise<void> {
    console.log(`Template ${event.templateName} completed in ${event.duration}ms`);
  }

  private async onError(event: ErrorEvent): Promise<void> {
    console.error(`Template failed: ${event.error.message}`);
  }
}
```

### Available Hooks

| Hook | When | Event Data |
| ---- | ---- | ---------- |
| `beforeExecute` | Before template runs | `templateName`, `answers` |
| `afterInquirer` | After questions answered | `templateName`, `answers` |
| `beforeProcess` | Before file processing | `templateName`, `files` |
| `afterProcess` | After file processing | `templateName`, `outputFiles` |
| `afterExecute` | After template completes | `templateName`, `duration` |
| `onError` | On error | `templateName`, `error` |
