# Plugin API Reference

This reference documents the complete API for developing CyanPrint plugins.

All plugins must implement this interface:

## PluginContext

Context provided during plugin initialization.

### Properties

| Property | Type | Description |
| -------- | ---- | ----------- |
| `config` | `object` | Plugin configuration from cyanprint.json |
| `logger` | `Logger` | Logging utilities |
| `hooks` | `HookRegistry` | Lifecycle hook registration |
| `plugins` | `PluginManager` | Access to other plugins |
| `files` | `FileHelper` | Read-only file operations |

### TypeScript Interface

  <Tab value="TypeScript">

## HookRegistry

Register lifecycle hooks to respond to template events.

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface HookRegistry {
  // Register hooks
  beforeExecute(callback: (event: BeforeExecuteEvent) => Promise<void>): void;
  afterInquirer(callback: (event: AfterInquirerEvent) => Promise<void>): void;
  beforeProcess(callback: (event: BeforeProcessEvent) => Promise<void>): void;
  afterProcess(callback: (event: AfterProcessEvent) => Promise<void>): void;
  afterExecute(callback: (event: AfterExecuteEvent) => Promise<void>): void;
  onError(callback: (event: ErrorEvent) => Promise<void>): void;
}
```

  </Tab>
  <Tab value=".NET">

```csharp
public class HookRegistry
{
    public void BeforeExecute(Func<BeforeExecuteEvent, Task> callback);
    public void AfterInquirer(Func<AfterInquirerEvent, Task> callback);
    public void BeforeProcess(Func<BeforeProcessEvent, Task> callback);
    public void AfterProcess(Func<AfterProcessEvent, Task> callback);
    public void AfterExecute(Func<AfterExecuteEvent, Task> callback);
    public void OnError(Func<ErrorEvent, Task> callback);
}
```

  </Tab>
  <Tab value="Python">

```python
class HookRegistry:
    def before_execute(self, callback: Callable[[BeforeExecuteEvent], Awaitable[None]]) -> None: ...
    def after_inquirer(self, callback: Callable[[AfterInquirerEvent], Awaitable[None]]) -> None: ...
    def before_process(self, callback: Callable[[BeforeProcessEvent], Awaitable[None]]) -> None: ...
    def after_process(self, callback: Callable[[AfterProcessEvent], Awaitable[None]]) -> None: ...
    def after_execute(self, callback: Callable[[AfterExecuteEvent], Awaitable[None]]) -> None: ...
    def on_error(self, callback: Callable[[ErrorEvent], Awaitable[None]]) -> None: ...
```

## Plugin Configuration

### cyanprint.json (Plugin)

```json
{
  "name": "@org/my-plugin",
  "version": "1.0.0",
  "type": "plugin",
  "entryPoint": "dist/index.js",
  "provides": ["feature1", "feature2"],
  "hooks": {
    "beforeExecute": true,
    "afterExecute": true
  },
  "config": {
    "defaultOption": "value"
  }
}
```

### cyanprint.json (Template using plugin)

```json
{
  "name": "my-template",
  "plugins": [
    {
      "name": "@org/my-plugin",
      "version": "^1.0.0",
      "config": {
        "customOption": "custom-value"
      }
    }
  ]
}
```

### Configuration Fields

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `name` | string | Yes | Plugin package name |
| `version` | string | Yes | Semantic version |
| `type` | string | Yes | Must be `"plugin"` |
| `entryPoint` | string | Yes | Path to compiled plugin |
| `provides` | string[] | No | List of provided capabilities |
| `hooks` | object | No | Which hooks to subscribe |
| `config` | object | No | Default configuration |
