# Plugin cyan.yaml

The `cyan.yaml` file provides metadata about your plugin. While optional, it's recommended for documentation and discovery.

## Basic Structure

```yaml
name: org/my-plugin
version: 1.0.0
description: A plugin that performs post-processing operations
author: Your Name
license: MIT
```

## Properties

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| `name` | `string` | Yes | Plugin identifier (org/name format) |
| `version` | `string` | Yes | Semantic version |
| `description` | `string` | No | Brief description |
| `author` | `string` | No | Author name or org |
| `license` | `string` | No | License identifier |
| `repository` | `string` | No | Source repository URL |
| `keywords` | `string[]` | No | Search keywords |
| `config` | `object` | No | Config schema definition |

## Full Example

```yaml
name: atomi/setup-plugin
version: 1.2.0
description: Plugin that sets up git, installs dependencies, and configures the project
author: Atomi
license: MIT
repository: https://github.com/atomi/cyan-plugin-setup
keywords:
  - setup
  - git
  - npm
  - initialization

config:
  properties:
    git:
      type: boolean
      description: Initialize git repository
      default: true
    installDeps:
      type: boolean
      description: Install dependencies
      default: true
    packageManager:
      type: string
      enum: [npm, bun, yarn, pnpm]
      description: Package manager to use
      default: npm
    formatter:
      type: string
      enum: [prettier, biome, none]
      description: Code formatter to run
      default: none
```

## Config Schema

Define expected configuration options:

```yaml
config:
  properties:
    option1:
      type: boolean
      description: Enable feature
      default: true

    option2:
      type: string
      description: A string option
      default: ""

    option3:
      type: number
      description: A numeric option

    option4:
      type: string
      enum: [choice1, choice2, choice3]
      description: An enum option

    nested:
      type: object
      properties:
        subOption:
          type: boolean
          default: false
```

## Usage in Templates

Templates reference plugins by name:

```yaml
# In template's cyan.yaml
plugins:
  - name: atomi/setup-plugin:1.2.0
    config:
      git: true
      installDeps: true
      packageManager: bun
      formatter: biome
```

## Versioning Best Practices

```yaml
# Latest stable
name: org/plugin:latest

# Specific version
name: org/plugin:1.2.0

# Major version range (latest 1.x.x)
name: org/plugin:1

# Pre-release
name: org/plugin:2.0.0-beta.1
```
