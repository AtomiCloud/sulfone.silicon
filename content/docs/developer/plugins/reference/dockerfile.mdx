# Plugin Dockerfile

Every plugin runs in a Docker container. The Dockerfile defines the runtime environment.

## Basic Dockerfile

```dockerfile
FROM oven/bun:1.1.31

WORKDIR /app

# Required: Mark as CyanPrint plugin
LABEL cyanprint.dev=true

# Install dependencies
COPY package.json bun.lockb* ./
RUN bun install

# Copy plugin code
COPY . .

# Run plugin
CMD ["bun", "run", "index.ts"]
```

## Required Elements

### Base Image

Use a Bun or Node.js base image:

```dockerfile
# Bun (recommended)
FROM oven/bun:1.1.31

# Node.js
FROM node:20-alpine

# With specific Bun version
FROM oven/bun:1.1.31-alpine
```

### CyanPrint Label

The `cyanprint.dev=true` label identifies the image as a CyanPrint component:

```dockerfile
LABEL cyanprint.dev=true
```

### Working Directory

Set a consistent working directory:

```dockerfile
WORKDIR /app
```

### Entry Point

Define how the plugin runs:

```dockerfile
# Using Bun
CMD ["bun", "run", "index.ts"]

# Using Node.js
CMD ["node", "index.js"]

# Using tsx (TypeScript with Node)
CMD ["npx", "tsx", "index.ts"]
```

## Optimized Dockerfile

### Multi-stage Build

```dockerfile
# Build stage
FROM oven/bun:1.1.31 AS builder

WORKDIR /app

COPY package.json bun.lockb* ./
RUN bun install --frozen-lockfile

COPY . .

# Runtime stage
FROM oven/bun:1.1.31-slim

WORKDIR /app

LABEL cyanprint.dev=true

COPY --from=builder /app /app

CMD ["bun", "run", "index.ts"]
```

### With Additional Tools

```dockerfile
FROM oven/bun:1.1.31

WORKDIR /app

LABEL cyanprint.dev=true

# Install additional tools if needed
RUN apt-get update && apt-get install -y \
    git \
    && rm -rf /var/lib/apt/lists/*

COPY package.json bun.lockb* ./
RUN bun install

COPY . .

CMD ["bun", "run", "index.ts"]
```

### Minimal Image

```dockerfile
FROM oven/bun:1.1.31-alpine

WORKDIR /app

LABEL cyanprint.dev=true

COPY package.json bun.lockb* ./
RUN bun install --production

COPY index.ts .

CMD ["bun", "run", "index.ts"]
```

## Dockerignore

Create a `.dockerignore` file to exclude unnecessary files:

```text
# Dependencies
node_modules
bun.lockb

# Git
.git
.gitignore

# Documentation
*.md
docs/

# IDE
.vscode
.idea

# OS files
.DS_Store
Thumbs.db

# Environment
.env
.env.*

# Test files
*.test.ts
*.spec.ts
__tests__/
```

## Size Optimization

| Technique | Savings | Trade-off |
|-----------|---------|-----------|
| Alpine base | ~100MB | May need musl compatibility |
| `--production` flag | ~20% | No dev dependencies |
| Multi-stage | ~30% | More complex build |
| Minimal copy | Varies | Manual optimization |

<Callout type="info">
Keep images small for faster pulls. Plugins are downloaded on every generation.
</Callout>

## Environment Variables

Pass environment variables to the plugin:

```dockerfile
FROM oven/bun:1.1.31

WORKDIR /app

LABEL cyanprint.dev=true

# Set environment variables
ENV NODE_ENV=production
ENV PLUGIN_TIMEOUT=300

COPY package.json bun.lockb* ./
RUN bun install

COPY . .

CMD ["bun", "run", "index.ts"]
```

## Port Configuration

Plugins communicate on port 5552:

```dockerfile
# Expose plugin port (informational)
EXPOSE 5552
```

<Callout type="warn">
Port 5552 is the standard plugin port. Don't change it unless you have a specific reason.
</Callout>
