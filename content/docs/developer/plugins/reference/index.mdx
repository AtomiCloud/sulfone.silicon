# Plugin Reference

Technical documentation for the CyanPrint plugin system.

This reference is organized into two main sections: **Project Setup** covers the structural files required to build and configure a plugin, while **SDK Reference** provides detailed documentation for the TypeScript SDK used to implement plugin logic.

## Project Setup

- [Project Structure](/docs/developer/plugins/reference/project-structure) - Standard directory layout and required files for plugin projects
- [cyan.yaml](/docs/developer/plugins/reference/cyan-yaml) - Configuration file for plugin metadata and config schema
- [Dockerfile](/docs/developer/plugins/reference/dockerfile) - Container configuration for CyanPrint plugins

## SDK Reference

- [SDK Overview](/docs/developer/plugins/reference/sdk/index) - Introduction to the plugin SDK
- [StartPluginWithLambda](/docs/developer/plugins/reference/sdk/start-plugin) - Entry point for plugin logic
- [Plugin Input/Output](/docs/developer/plugins/reference/sdk/input-output) - Type definitions for plugin interfaces
- [Type Definitions](/docs/developer/plugins/reference/sdk/types) - Complete type reference
