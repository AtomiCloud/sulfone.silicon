# Plugin Tutorials

Learn plugin development with step-by-step tutorials.

## Tutorials

- [Your First Plugin](/docs/developer/plugins/tutorials/first-plugin) - Create a plugin that runs post-processing commands like `git init` and dependency installation after file generation

**What you'll learn:**
- Setting up a plugin project
- Using `StartPluginWithLambda` with `CyanPluginInput`
- Running shell commands
- Accessing plugin configuration
- Returning `PluginOutput`
- Building and testing

**Prerequisites:**
- Docker installed and running
- Basic TypeScript knowledge
