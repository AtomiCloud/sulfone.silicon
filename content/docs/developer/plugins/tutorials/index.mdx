# Plugin Tutorials

Learn plugin development with step-by-step tutorials.

## Tutorials

### [Your First Plugin](/developer/plugins/tutorials/first-plugin)

Create a plugin that runs post-processing commands after file generation.

**What you'll learn:**
- Setting up a plugin project
- Using `StartPluginWithLambda`
- Running shell commands
- Accessing plugin configuration
- Building and testing

**Prerequisites:**
- Docker installed and running
- Basic TypeScript knowledge
