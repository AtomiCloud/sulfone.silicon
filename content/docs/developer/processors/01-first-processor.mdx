# First Processor

Processors transform file content during template execution. This tutorial guides you through creating a custom processor.

**Time estimate**: 15-20 minutes

## What is a Processor?

A processor is a CyanPrint artifact that:

1. **Receives** file content as input
2. **Transforms** the content based on configuration
3. **Returns** transformed content

Common processor use cases:

- Template variable substitution (default processor)
- Code formatting (Prettier, ESLint fix)
- JSON/YAML transformation
- Custom DSL compilation
- File format conversion

## Create a Simple Processor

Let's create a processor that converts text to uppercase:

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
// src/index.ts
import { CyanProcessorInput, ProcessorOutput, ICyanProcessor } from '@atomicloud/helium-sdk';

export default class UppercaseProcessor implements ICyanProcessor {
  async process(input: CyanProcessorInput): Promise<ProcessorOutput> {
    // Get the file content
    const content = input.content;

    // Transform to uppercase
    const transformed = content.toUpperCase();

    // Return the output
    return {
      content: transformed,
      encoding: input.encoding
    };
  }
}
```

## Configure the Processor

Create `cyanprint.json`:

```json
{
  "name": "uppercase-processor",
  "version": "1.0.0",
  "description": "Converts file content to uppercase",
  "type": "processor",
  "entryPoint": "dist/index.js",
  "fileExtensions": [".txt", ".md"]
}
```

### Configuration Options

| Field | Description | Required |
| ----- | ----------- | -------- |
| `name` | Processor package name | Yes |
| `version` | Semantic version | Yes |
| `type` | Must be `"processor"` | Yes |
| `entryPoint` | Path to compiled processor | Yes |
| `fileExtensions` | Auto-apply to these extensions | No |
| `config` | Default configuration | No |

## Accessing File Information

The input provides file metadata:

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
export default class MetadataProcessor implements ICyanProcessor {
  async process(input: CyanProcessorInput): Promise<ProcessorOutput> {
    // Available metadata
    const {
      content,      // File content as string
      filePath,     // Relative path to file
      encoding,     // File encoding (e.g., 'utf-8')
      extension,    // File extension (e.g., '.ts')
      config        // Processor configuration
    } = input;

    // Log for debugging
    console.log(`Processing: ${filePath}`);

    // Process based on extension
    let transformed = content;
    if (extension === '.json') {
      transformed = this.processJson(content);
    } else if (extension === '.md') {
      transformed = this.processMarkdown(content);
    }

    return { content: transformed, encoding };
  }

  private processJson(content: string): string {
    const parsed = JSON.parse(content);
    // Transform JSON
    return JSON.stringify(parsed, null, 2);
  }

  private processMarkdown(content: string): string {
    // Transform Markdown
    return content;
  }
}
```

```csharp
public class MetadataProcessor : ICyanProcessor
{
    public async Task<ProcessorOutput> ProcessAsync(CyanProcessorInput input)
    {
        // Available metadata
        var content = input.Content;      // File content as string
        var filePath = input.FilePath;    // Relative path to file
        var encoding = input.Encoding;    // File encoding
        var extension = input.Extension;  // File extension
        var config = input.Config;        // Processor configuration

        // Log for debugging
        Console.WriteLine($"Processing: {filePath}");

        // Process based on extension
        string transformed = content;
        if (extension == ".json")
        {
            transformed = ProcessJson(content);
        }
        else if (extension == ".md")
        {
            transformed = ProcessMarkdown(content);
        }

        return new ProcessorOutput
        {
            Content = transformed,
            Encoding = encoding
        };
    }

    private string ProcessJson(string content)
    {
        var parsed = JsonSerializer.Deserialize<JsonElement>(content);
        // Transform JSON
        return JsonSerializer.Serialize(parsed, new JsonSerializerOptions { WriteIndented = true });
    }

    private string ProcessMarkdown(string content)
    {
        // Transform Markdown
        return content;
    }
}
```

```python
import json

class MetadataProcessor(ICyanProcessor):
    async def process(self, input: CyanProcessorInput) -> ProcessorOutput:
        # Available metadata
        content = input.content       # File content as string
        file_path = input.file_path   # Relative path to file
        encoding = input.encoding     # File encoding
        extension = input.extension   # File extension
        config = input.config         # Processor configuration

        # Log for debugging
        print(f"Processing: {file_path}")

        # Process based on extension
        transformed = content
        if extension == ".json":
            transformed = self._process_json(content)
        elif extension == ".md":
            transformed = self._process_markdown(content)

        return ProcessorOutput(
            content=transformed,
            encoding=encoding
        )

    def _process_json(self, content: str) -> str:
        parsed = json.loads(content)
        # Transform JSON
        return json.dumps(parsed, indent=2)

    def _process_markdown(self, content: str) -> str:
        # Transform Markdown
        return content
```

## Accessing Answers

Processors can access template answers:

```ts
export default class AnswerAwareProcessor implements ICyanProcessor {
  async process(input: CyanProcessorInput): Promise<ProcessorOutput> {
    // Access answers from the template
    const answers = input.answers;

    // Use answers in transformation
    const projectName = answers.projectName || 'unknown';
    const author = answers.author || 'Anonymous';

    // Replace placeholders
    let content = input.content;
    content = content.replace(/\{\{projectName\}\}/g, projectName);
    content = content.replace(/\{\{author\}\}/g, author);

    return {
      content,
      encoding: input.encoding
    };
  }
}
```

## Error Handling

Handle errors gracefully:

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
export default class SafeProcessor implements ICyanProcessor {
  async process(input: CyanProcessorInput): Promise<ProcessorOutput> {
    try {
      // Validate input
      if (!input.content) {
        return {
          content: '',
          encoding: input.encoding,
          skipped: true,
          skipReason: 'Empty content'
        };
      }

      // Process content
      const transformed = await this.transform(input.content, input.config);

      return {
        content: transformed,
        encoding: input.encoding
      };
    } catch (error) {
      // Return error information
      return {
        content: input.content,  // Return original on error
        encoding: input.encoding,
        error: error instanceof Error ? error.message : 'Unknown error'
      };
    }
  }

  private async transform(content: string, config: any): Promise<string> {
    // Transformation logic
    return content;
  }
}
```

```csharp
            if (string.IsNullOrEmpty(input.Content))

                    SkipReason = "Empty content"

                Content = input.Content,  // Return original on error
```
