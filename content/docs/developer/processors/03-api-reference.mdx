## CyanProcessorInput

Input passed to the processor's `process` method.

### Properties

| Property | Type | Description |
| -------- | ---- | ----------- |
| `content` | `string` | File content as string |
| `filePath` | `string` | Relative path to the file |
| `encoding` | `string` | File encoding (e.g., 'utf-8') |
| `extension` | `string` | File extension including dot (e.g., '.ts') |
| `config` | `object` | Processor configuration from template |
| `answers` | `Answers` | Template user answers |
| `files` | `CyanFileHelper` | File operations helper |
| `determinism` | `Determinism` | Deterministic random generation |
| `logger` | `Logger` | Logging utilities |

### TypeScript Interface

## ProcessorOutput

Output returned from the processor's `process` method.

### Properties

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `content` | `string` | Yes | Transformed file content |
| `encoding` | `string` | Yes | Output encoding |
| `skipped` | `boolean` | No | Whether file was skipped |
| `skipReason` | `string` | No | Reason for skipping |
| `error` | `string` | No | Error message if processing failed |
| `additionalFiles` | `AdditionalFile[]` | No | Additional files to create |

### TypeScript Interface

## CyanFileHelper

File operations available within processors.

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface CyanFileHelper {
  // Read file content
  read(path: string, encoding?: string): Promise<string>;

  // Read and parse JSON
  readJson<T>(path: string): Promise<T>;

  // Write file content
  write(path: string, content: string, encoding?: string): Promise<void>;

  // Write object as JSON
  writeJson(path: string, data: any, indent?: number): Promise<void>;

  // Check if file exists
  exists(path: string): Promise<boolean>;

  // Copy file
  copy(source: string, destination: string): Promise<void>;

  // Delete file
  delete(path: string): Promise<void>;

  // Create directory
  mkdir(path: string, recursive?: boolean): Promise<void>;

  // List directory contents
  readdir(path: string): Promise<string[]>;

  // Get file stats
  stat(path: string): Promise<FileStats>;

  // Check if path is directory
  isDirectory(path: string): Promise<boolean>;

  // Check if path is file
  isFile(path: string): Promise<boolean>;
}

interface FileStats {
  size: number;
  created: Date;
  modified: Date;
  isDirectory: boolean;
  isFile: boolean;
}
```

## Determinism

Deterministic random generation (same as template context).

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface Determinism {
  // Generate deterministic UUID
  uuid(): string;

  // Random float between 0 and 1
  random(): number;

  // Random integer in range (inclusive)
  randomInt(min: number, max: number): number;

  // Random string of specified length
  randomString(length: number): string;

  // Shuffle array deterministically
  shuffle<T>(array: T[]): T[];

  // Pick random element
  pick<T>(array: T[]): T;

  // Boolean with probability
  chance(probability: number): boolean;
}
```

## Answers

Read-only access to template answers.

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface Answers {
  // Direct property access
  [key: string]: any;

  // Get typed value
  get<T>(key: string): T | undefined;

  // Get with default
  getOrDefault<T>(key: string, defaultValue: T): T;

  // Check if answer exists
  has(key: string): boolean;
}
```

  </Tab>

## Processor Configuration

### cyanprint.json

```json
{
  "name": "@org/my-processor",
  "version": "1.0.0",
  "type": "processor",
  "entryPoint": "dist/index.js",
  "fileExtensions": [".txt", ".md"],
  "config": {
    "defaultOption": "value"
  }
}
```

### Configuration Fields

| Field | Type | Required | Description |
| ----- | ---- | -------- | ----------- |
| `name` | string | Yes | Processor package name |
| `version` | string | Yes | Semantic version |
| `type` | string | Yes | Must be `"processor"` |
| `entryPoint` | string | Yes | Path to compiled processor |
| `fileExtensions` | string[] | No | Auto-apply to these extensions |
| `config` | object | No | Default configuration |
