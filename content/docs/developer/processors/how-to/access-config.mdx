# Access Processor Config

Processors receive configuration from the template through `input.config`. This allows templates to customize processor behavior.

## ProcessorConfig Type

<TypeTable
  type={{
    customSetting: {
      type: 'boolean',
      description: 'Enable custom behavior',
    },
    features: {
      type: 'string[]',
      description: 'List of enabled features',
    },
    outputFormat: {
      type: "'json' | 'yaml'",
      description: 'Output format for generated files',
    },
  }}
/>

## Template Configuration

In the template's `index.ts`, pass config to the processor:

```ts index.ts -c
// Template's index.ts
import { StartTemplateWithLambda, GlobType } from '@atomicloud/cyan-sdk';

interface ProcessorConfig {
  customSetting: boolean;
  features: string[];
  outputFormat: 'json' | 'yaml';
}

StartTemplateWithLambda(async (i, d) => {
  // Ask user for preferences
  const features = await i.checkbox(
    'Select features:',
    ['docker', 'ci', 'testing'],
    'project.features',
    'Choose features'
  );

  const format = await i.select(
    'Output format:',
    ['json', 'yaml'],
    'config.format',
    'Choose format'
  );

  return {
    processors: [{
      name: 'myorg/my-processor',
      files: [{ root: 'templates', glob: '**/*', exclude: [], type: GlobType.Template }],
      config: {
        customSetting: true,
        features: features,
        outputFormat: format
      } as ProcessorConfig
    }]
  };
});
```
