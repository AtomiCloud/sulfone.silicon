# StartProcessorWithLambda

The entry point for processor logic. Wrap your processor function with this to create a valid CyanPrint processor.

## Signature

```ts title="processor.ts"
function StartProcessorWithLambda(
  handler: (input: CyanProcessorInput, fileHelper: CyanFileHelper) => Promise<ProcessorOutput>
): void;
```

## Parameters

### handler

The async function that implements processor logic.

| Parameter | Type | Description |
|-----------|------|-------------|
| `input` | `CyanProcessorInput` | Contains directories, globs, and config |
| `fileHelper` | `CyanFileHelper` | File operations API |

**Returns:** `Promise<ProcessorOutput>`

## Usage

<Tabs items={['TypeScript', 'Python', 'C#']}>
  <Tab value="TypeScript">

```ts title="processor.ts"
import { StartProcessorWithLambda } from '@atomicloud/cyan-sdk';

StartProcessorWithLambda(async (input, fileHelper) => {
  // 1. Load files
  const files = fileHelper.resolveAll();

  // 2. Transform content
  files.forEach(file => {
    file.content = transform(file.content);
  });

  // 3. Write output
  files.forEach(file => {
    file.writeFile();
  });

  // 4. Return output directory
  return { directory: input.writeDir };
});
```

## CyanProcessorInput

| Property | Type | Description |
|----------|------|-------------|
| `readDir` | `string` | Path to source files (set by CLI, typically `/workspace/cyanprint/`) |
| `writeDir` | `string` | Path for output files (set by CLI, typically `/workspace/output/`) |
| `globs` | `CyanGlob[]` | File patterns from template |
| `config` | `unknown` | Configuration from template (cast to your config type) |

## ProcessorOutput

| Property | Type | Description |
|----------|------|-------------|
| `directory` | `string` | Must be `input.writeDir` |

<Callout type="warn" title="Required">
  The `directory` property in the return value **must** be `input.writeDir`.
  Returning any other path will cause the processor to fail.
</Callout>

import { StartProcessorWithLambda } from '@atomicloud/cyan-sdk';

StartProcessorWithLambda(async (input, fileHelper) => {
  const files = fileHelper.resolveAll();

  for (const file of files) {
    // Access file properties

## Error Handling

<Tabs items={['TypeScript', 'Python', 'C#']}>
  <Tab value="TypeScript">

```ts
StartProcessorWithLambda(async (input, fileHelper) => {
  try {
    const files = fileHelper.resolveAll();

    if (files.length === 0) {
      throw new Error('No files matched the processor globs');
    }

    for (const file of files) {
      try {
        file.content = transform(file.content);
        file.writeFile();
      } catch (err) {
        console.error(`Failed to process ${file.relative}:`, err);
        // Continue with other files or rethrow
      }
    }

    return { directory: input.writeDir };
  } catch (err) {
    console.error('Processor failed:', err);
    throw err;
  }
});
```
