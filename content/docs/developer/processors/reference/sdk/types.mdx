# Type Definitions

Complete type reference for the processor SDK.

## Core Types

### CyanProcessorInput

The input type received by processor handlers.

```ts
interface CyanProcessorInput {
  /**
   * Path to source files from blob image
   * @example "/workspace/cyanprint/"
   */
  readDir: string;

  /**
   * Path where processed files should be written
   * @example "/workspace/output/"
   */
  writeDir: string;

  /**
   * File patterns passed from template configuration
   */
  globs: CyanGlob[];

  /**
   * Custom configuration from template's processor config
   * Cast to your expected type when using
   */
  config: unknown;
}
```

### ProcessorOutput

```ts
interface ProcessorOutput {
  /**
   * Output directory - must be input.writeDir
   */
  readonly directory: string;
}
```

### GlobType Enum

Specifies the type of file matching for a glob pattern.

```ts
enum GlobType {
  /**
   * Files will be processed through the processor
   */
  Template = 0,

  /**
   * Files will be copied directly without processing
   */
  Copy = 1,
}
```

### CyanGlob

```ts
interface CyanGlob {
  /**
   * Base directory for glob matching
   * @optional Defaults to root of read directory
   * @example "templates"
   */
  root?: string | null;

  /**
   * Glob pattern to match files
   * @example "**/*.md"
   */
  glob: string;

  /**
   * Patterns to exclude from matching
   * @example ["**/*.test.ts"]
   */
  exclude: string[];

  /**
   * Type of glob - determines how files are handled
   */
  type: GlobType;
}
```

## VirtualFile Types

All VirtualFile types are **classes**, not interfaces.

### VirtualFile

File with loaded content (from `resolveAll()` or `read()`).

```ts
class VirtualFile {
  constructor(
    public baseRead: string,
    public baseWrite: string,
    public relative: string,
    public content: string,
  ) {}

  /**
   * Full path to source file
   */
  get read(): string;

  /**
   * Full path to output file
   */
  get write(): string;

  /**
   * Path relative to read directory
   * @example "docs/readme.md"
   */
  relative: string;

  /**
   * File contents as string
   */
  content: string;

  /**
   * Write file to output directory
   */
  writeFile(): void;
}
```

### VirtualFileReference

Lazy-loaded file reference (from `get()`).

```ts
class VirtualFileReference {
  constructor(
    public baseRead: string,
    public baseWrite: string,
    public relative: string,
  ) {}

  /**
   * Full path to source file
   */
  get read(): string;

  /**
   * Full path to output file
   */
  get write(): string;

  /**
   * Path relative to read directory
   */
  relative: string;

  /**
   * Load file content and return VirtualFile
   * @returns VirtualFile with loaded content
   */
  readFile(): VirtualFile;
}
```

### VirtualFileStream

Streaming file access (from `readAsStream()`). Wraps Node.js streams directly.

```ts
class VirtualFileStream {
  constructor(
    public reader: fs.ReadStream,
    public writer: fs.WriteStream,
  ) {}
}
```

## CyanFileHelper

Class providing file operations for processors.

```ts
class CyanFileHelper {
  constructor(
    private readonly _readDir: string,
    private readonly _writeDir: string,
    private readonly globs: CyanGlob[],
  ) {}

  /**
   * Resolved read directory path
   */
  get readDir(): string;

  /**
   * Resolved write directory path
   */
  get writeDir(): string;

  /**
   * Load all files matching processor globs into memory
   * Files with GlobType.Copy are copied directly
   * Files with GlobType.Template are loaded and returned
   * @returns Array of files with content
   */
  resolveAll(): VirtualFile[];

  /**
   * Load specific files matching glob pattern
   * @param glob - Pattern to match
   * @returns Array of matching files with content
   */
  read(glob: CyanGlob): VirtualFile[];

  /**
   * Get file references without loading content
   * @param glob - Pattern to match
   * @returns Array of file references
   */
  get(glob: CyanGlob): VirtualFileReference[];

  /**
   * Stream files for memory-efficient processing
   * @param glob - Pattern to match
   * @returns Array of streaming file handles
   */
  readAsStream(glob: CyanGlob): VirtualFileStream[];

  /**
   * Copy files directly to output without loading
   * @param glob - Pattern to match
   */
  copy(glob: CyanGlob): void;
}
```

## Example Patterns

The following sections show common patterns you can use in your processors. These are not SDK types, but examples of how to structure your code.

### Common Config Patterns

```ts
// Variable substitution config (like default processor)
interface VariableConfig {
  vars: Record<string, string | number | boolean>;
}

// Feature flags
interface FeatureConfig {
  features: string[];
}

// Output formatting
interface FormatConfig {
  indent?: number;
  newline?: 'lf' | 'crlf';
  encoding?: 'utf-8' | 'ascii';
}

// Combined config
interface ProcessorConfig extends FeatureConfig, FormatConfig {
  // Processor-specific options
  customOption?: string;
}
```

### Error Handling Patterns

```ts
// Suggested error classes for custom error handling
class ProcessorError extends Error {
  constructor(message: string, public readonly file?: string) {
    super(message);
    this.name = 'ProcessorError';
  }
}

class FileNotFoundError extends ProcessorError {
  constructor(path: string) {
    super(`File not found: ${path}`, path);
    this.name = 'FileNotFoundError';
  }
}

class TransformError extends ProcessorError {
  constructor(message: string, file: string, public readonly line?: number) {
    super(`${message} in ${file}${line ? `:${line}` : ''}`, file);
    this.name = 'TransformError';
  }
}
```

## Type Guard Pattern

Example pattern for safely casting the config:

```ts
// Example type guard for checking config shape
function isVariableConfig(config: unknown): config is VariableConfig {
  return typeof config === 'object' && config !== null && 'vars' in config;
}

// Usage
StartProcessorWithLambda(async (input, fileHelper) => {
  if (isVariableConfig(input.config)) {
    const vars = input.config.vars;
    // ...
  }

  return {
    directory: input.writeDir,
  };
});
```
