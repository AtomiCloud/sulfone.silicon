A resolver project follows a standard layout for consistency and ease of development.

## File Descriptions

### `index.ts`

The main entry point using `StartResolverWithLambda`:

```ts index.ts -c
import { ResolverOutput, StartResolverWithLambda } from '@atomicloud/cyan-sdk';

StartResolverWithLambda(async (input): Promise<ResolverOutput> => {
  // Sort files by layer
  const sorted = [...input.files].sort(
    (a, b) => a.origin.layer - b.origin.layer
  );

  // Merge content
  let merged = {};
  for (const file of sorted) {
    merged = { ...merged, ...JSON.parse(file.content) };
  }

  return {
    path: input.files[0].path,
    content: JSON.stringify(merged, null, 2)
  };
});
```

### `package.json`

Define dependencies and scripts:

```json package.json -c
{
  "name": "my-resolver",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "bun run index.ts"
  },
  "dependencies": {
    "@atomicloud/cyan-sdk": "^1.0.0"
  },
  "devDependencies": {
    "@types/bun": "latest"
  }
}
```

### `Dockerfile`

Container definition for the resolver:

```dockerfile Dockerfile -c
FROM oven/bun:1.1.30

WORKDIR /app

# Required: Mark as CyanPrint resolver
LABEL cyanprint.dev=true

# Install dependencies
COPY package.json .
COPY bun.lock .
RUN bun install

# Copy resolver code
COPY . .

# Run resolver
CMD ["bun", "run", "index.ts"]
```

<Callout type="warn">
The `LABEL cyanprint.dev=true` line is **required** for the container to be recognized as a CyanPrint resolver.
</Callout>

### `cyan.yaml`

Metadata for registry publishing:

```yaml cyan.yaml -c
username: your-username
name: my-resolver
description: JSON file resolver for layered templates
project: https://github.com/org/my-project
source: https://github.com/org/my-resolver
email: contact@example.com
tags:
  - json
  - merge
  - resolver
readme: README.md
```

### `tsconfig.json`

TypeScript configuration

```json tsconfig.json -c
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "skipLibCheck": true,
    "esModuleInterop": true
  },
  "include": ["*.ts", "src/**/*.ts"]
}
```
