The SDK provides the entry point functions and type definitions for building resolvers.

## Entry Point
Each SDK provides an entry point function that starts the resolver server and handles incoming file resolution requests.

<Tabs items={['TypeScript', 'Python', 'C#']}>
  <Tab value="TypeScript">

```ts index.ts -c
import { StartResolverWithLambda } from '@atomicloud/cyan-sdk';

StartResolverWithLambda(async (input) => {
  // Your resolver logic here
  return {
    path: input.files[0].path,
    content: "merged content"
  };
});
```

  </Tab>
  <Tab value="Python">

```python main.py -c
from cyanprintsdk.domain.resolver.input import ResolverInput
from cyanprintsdk.domain.resolver.output import ResolverOutput
from cyanprintsdk.main import start_resolver_with_fn


async def resolver(input: ResolverInput) -> ResolverOutput:
    # Your resolver logic here
    return ResolverOutput(
        path=input.files[0].path,
        content="merged content"
    )


if __name__ == "__main__":
    start_resolver_with_fn(resolver)
```

  </Tab>
  <Tab value="C#">

```cs Program.cs -c
using sulfone_helium;
using sulfone_helium.Domain.Resolver;

CyanEngine.StartResolver(
    args,
    async (ResolverInput input) =>
    {
        // Your resolver logic here
        return new ResolverOutput(
            input.Files.First().Path,
            "merged content"
        );
    }
);
```
