Each SDK provides an entry point function that starts the resolver server and handles incoming file resolution requests.

## Server Behavior
The resolver server:
1. Starts on port **5553**
2. Exposes `/api/resolve` endpoint
3. Expects JSON request body matching `ResolverInput`
4. Returns JSON response matching `ResolverOutput`
