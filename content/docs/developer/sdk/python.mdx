# Python SDK Reference

Complete API reference for the `cyanprint-helium` package.

## Installation

```bash
pip install cyanprint-helium
```

## Core Classes

### ICyanTemplate

All templates inherit from this abstract class:

```python
from abc import ABC, abstractmethod

class ICyanTemplate(ABC):
    @abstractmethod
    async def execute(self, cyan: Cyan) -> None:
        pass
```

### ICyanProcessor

All processors inherit from this abstract class:

```python
class ICyanProcessor(ABC):
    @abstractmethod
    async def process(self, input: CyanProcessorInput) -> ProcessorOutput:
        pass
```

### ICyanPlugin

All plugins inherit from this abstract class:

```python
class ICyanPlugin(ABC):
    @property
    @abstractmethod
    def name(self) -> str:
        pass

    @property
    @abstractmethod
    def version(self) -> str:
        pass

    @abstractmethod
    async def initialize(self, context: PluginContext) -> None:
        pass

    async def dispose(self) -> None:
        pass
```

## Answers

Access to user answers.

```python
class Answers:
    # Dictionary-like access
    def __getitem__(self, key: str) -> Any: ...
    def __setitem__(self, key: str, value: Any) -> None: ...

    # Methods
    def get(self, key: str, default: Any = None) -> Any: ...
    def has(self, key: str) -> bool: ...
    def set(self, key: str, value: Any) -> None: ...

    # Conditional prompting
    async def get_or_prompt(self, key: str, options: dict) -> str: ...
    async def get_or_prompt_select(self, key: str, options: dict) -> str: ...
    async def get_or_prompt_checkbox(self, key: str, options: dict) -> List[str]: ...
```

## Plugin Types

### PluginContext

```python
class PluginContext:
    config: dict
    logger: Logger
    hooks: HookRegistry
    plugins: PluginManager
    files: FileHelper
```

### HookRegistry

```python
class HookRegistry:
    def before_execute(self, callback: Callable[[BeforeExecuteEvent], Awaitable[None]]) -> None: ...
    def after_inquirer(self, callback: Callable[[AfterInquirerEvent], Awaitable[None]]) -> None: ...
    def before_process(self, callback: Callable[[BeforeProcessEvent], Awaitable[None]]) -> None: ...
    def after_process(self, callback: Callable[[AfterProcessEvent], Awaitable[None]]) -> None: ...
    def after_execute(self, callback: Callable[[AfterExecuteEvent], Awaitable[None]]) -> None: ...
    def on_error(self, callback: Callable[[ErrorEvent], Awaitable[None]]) -> None: ...
```

### Hook Event Types

```python
class BeforeExecuteEvent:
    template_name: str
    template_version: str
    answers: dict
    timestamp: datetime

class AfterInquirerEvent:
    template_name: str
    answers: dict
    question_count: int

class BeforeProcessEvent:
    template_name: str
    input_file_count: int
    input_files: List[str]

class AfterProcessEvent:
    template_name: str
    output_file_count: int
    output_files: List[str]
    process_duration: int

class AfterExecuteEvent:
    template_name: str
    success: bool
    duration: int
    file_count: int
    errors: List[str]

class ErrorEvent:
    template_name: str
    error: Exception
    phase: str  # "inquirer", "process", "output", "unknown"
    recoverable: bool
```
