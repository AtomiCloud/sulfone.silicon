# Inquirer Methods

This reference documents all available inquirer methods for collecting user input.

import { Tab, Tabs } from 'fumadocs-ui/components/tabs';

## text

Collect free-form text input from the user.

### Options

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `message` | string | Yes | The prompt message displayed to the user |
| `default` | string | No | Default value if user presses Enter |
| `placeholder` | string | No | Placeholder text shown in input |
| `validate` | function | No | Validation function, returns `true` or error message |
| `transformer` | function | No | Function to transform display value |
| `required` | boolean | No | Whether input is required |

### Examples

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
// Basic text input
const name = await cyan.inquirer.text({
  message: 'Project name:'
});

// With default value
const name = await cyan.inquirer.text({
  message: 'Project name:',
  default: 'my-project'
});

// With validation
const email = await cyan.inquirer.text({
  message: 'Email:',
  validate: (value) => {
    if (!value.includes('@')) {
      return 'Please enter a valid email';
    }
    return true;
  }
});

// With transformer (display only)
const secret = await cyan.inquirer.text({
  message: 'API Key:',
  transformer: (value) => value.replace(/./g, '*')
});
```

  </Tab>
  <Tab value=".NET">

```csharp
// Basic text input
var name = await cyan.Inquirer.TextAsync(new TextOptions
{
    Message = "Project name:"
});

// With default value
var name = await cyan.Inquirer.TextAsync(new TextOptions
{
    Message = "Project name:",
    Default = "my-project"
});

// With validation
var email = await cyan.Inquirer.TextAsync(new TextOptions
{
    Message = "Email:",
    Validate = value =>
    {
        if (!value.Contains("@"))
        {
            return "Please enter a valid email";
        }
        return null; // null means valid
    }
});

// With transformer (display only)
var secret = await cyan.Inquirer.TextAsync(new TextOptions
{
    Message = "API Key:",
    Transformer = value => new string('*', value.Length)
});
```

  </Tab>
  <Tab value="Python">

```python
# Basic text input
name = await cyan.inquirer.text(
    message="Project name:"
)

# With default value
name = await cyan.inquirer.text(
    message="Project name:",
    default="my-project"
)

# With validation
async def validate_email(value):
    if "@" not in value:
        return "Please enter a valid email"
    return True

email = await cyan.inquirer.text(
    message="Email:",
    validate=validate_email
)

# With transformer (display only)
def mask_value(value):
    return "*" * len(value)

secret = await cyan.inquirer.text(
    message="API Key:",
    transformer=mask_value
)
```

  </Tab>
</Tabs>

## select

Allow user to select a single option from a list.

### Options

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `message` | string | Yes | The prompt message |
| `options` | array | Yes | Array of options (strings or objects) |
| `default` | string | No | Default selected option value |
| `pageSize` | number | No | Number of options to display at once |

### Option Object

| Property | Type | Description |
| -------- | ---- | ----------- |
| `value` | string | The value returned when selected |
| `label` | string | Display text for the option |
| `description` | string | Optional description shown below label |
| `disabled` | boolean | Whether option is selectable |

### Examples

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
// Simple string options
const framework = await cyan.inquirer.select({
  message: 'Framework:',
  options: ['React', 'Vue', 'Svelte']
});

// Object options with descriptions
const framework = await cyan.inquirer.select({
  message: 'Framework:',
  options: [
    {
      value: 'react',
      label: 'React',
      description: 'A JavaScript library for building user interfaces'
    },
    {
      value: 'vue',
      label: 'Vue',
      description: 'The progressive JavaScript framework'
    },
    {
      value: 'svelte',
      label: 'Svelte',
      description: 'Cybernetically enhanced web apps'
    }
  ],
  default: 'react'
});

// With disabled option
const plan = await cyan.inquirer.select({
  message: 'Select plan:',
  options: [
    { value: 'free', label: 'Free' },
    { value: 'pro', label: 'Pro' },
    { value: 'enterprise', label: 'Enterprise (Coming Soon)', disabled: true }
  ]
});

// With pagination
const template = await cyan.inquirer.select({
  message: 'Select template:',
  options: largeTemplateList,
  pageSize: 10
});
```

## checkbox

Allow user to select multiple options from a list.

### Options

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `message` | string | Yes | The prompt message |
| `options` | array | Yes | Array of options |
| `required` | boolean | No | Require at least one selection |
| `min` | number | No | Minimum number of selections |
| `max` | number | No | Maximum number of selections |
| `pageSize` | number | No | Number of options visible |

### Option Object

| Property | Type | Description |
| -------- | ---- | ----------- |
| `value` | string | The value returned when selected |
| `label` | string | Display text |
| `checked` | boolean | Pre-selected by default |
| `disabled` | boolean | Option cannot be toggled |

### Examples

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
// Simple string options
const features = await cyan.inquirer.checkbox({
  message: 'Features:',
  options: ['TypeScript', 'ESLint', 'Prettier', 'Vitest']
});

// With pre-selected options
const features = await cyan.inquirer.checkbox({
  message: 'Features:',
  options: [
    { value: 'typescript', label: 'TypeScript', checked: true },
    { value: 'eslint', label: 'ESLint', checked: true },
    { value: 'prettier', label: 'Prettier' },
    { value: 'vitest', label: 'Vitest' }
  ]
});

// With min/max constraints
const features = await cyan.inquirer.checkbox({
  message: 'Select 2-4 features:',
  options: featureList,
  min: 2,
  max: 4
});

// Require at least one selection
const packages = await cyan.inquirer.checkbox({
  message: 'Select packages:',
  options: packageList,
  required: true
});
```

  </Tab>
  <Tab value=".NET">

## password

Collect masked text input for sensitive data.

### Options

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `message` | string | Yes | The prompt message |
| `mask` | string | No | Character to mask input (default: `*`) |
| `validate` | function | No | Validation function |

### Examples

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
// Basic password input
const apiKey = await cyan.inquirer.password({
  message: 'API Key:'
});

// With custom mask
const token = await cyan.inquirer.password({
  message: 'Access Token:',
  mask: '•'
});

// With validation
const password = await cyan.inquirer.password({
  message: 'Password:',
  validate: (value) => {
    if (value.length < 8) {
      return 'Password must be at least 8 characters';
    }
    return true;
  }
});
```

  </Tab>
  <Tab value=".NET">

```csharp
// Basic password input
var apiKey = await cyan.Inquirer.PasswordAsync(new PasswordOptions
{
    Message = "API Key:"
});

// With custom mask
var token = await cyan.Inquirer.PasswordAsync(new PasswordOptions
{
    Message = "Access Token:",
    Mask = "•"
});

// With validation
var password = await cyan.Inquirer.PasswordAsync(new PasswordOptions
{
    Message = "Password:",
    Validate = value =>
    {
        if (value.Length < 8)
        {
            return "Password must be at least 8 characters";
        }
        return null;
    }
});
```

  </Tab>
  <Tab value="Python">

```python
# Basic password input

    message="API Key:"
)

    if len(value) < 8:
        return "Password must be at least 8 characters"
    return True

password = await cyan.inquirer.password(
    message="Password:",
    validate=validate_password
)
```

## date

Collect date input from the user.

### Options

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `message` | string | Yes | The prompt message |
| `default` | Date | No | Default date value |
| `min` | Date | No | Minimum selectable date |
| `max` | Date | No | Maximum selectable date |
| `format` | string | No | Display format (default: `YYYY-MM-DD`) |

### Examples

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
// Basic date input
const startDate = await cyan.inquirer.date({
  message: 'Start date:'
});

  message: 'Project deadline:',
  default: new Date('2025-12-31')
});

// With date range
const eventDate = await cyan.inquirer.date({
  message: 'Event date:',
  min: new Date(),
  max: new Date('2025-12-31')
});

// Custom format
const birthday = await cyan.inquirer.date({
  message: 'Birthday:',
  format: 'MM/DD/YYYY'
});
```

## expand

Compact selection prompt with single-character shortcuts.

### Options

| Property | Type | Required | Description |
| -------- | ---- | -------- | ----------- |
| `message` | string | Yes | The prompt message |
| `options` | array | Yes | Array of expand options |
| `default` | string | No | Default key |

### Option Object

| Property | Type | Description |
| -------- | ---- | ----------- |
| `key` | string | Single character shortcut |
| `name` | string | Full option name |
| `value` | any | Value returned when selected |

### Examples

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>

const action = await cyan.inquirer.expand({
