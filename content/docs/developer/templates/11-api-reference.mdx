# Template API Reference

This reference documents the complete API for developing CyanPrint templates.

## ICyanTemplate Interface

All templates must implement the `ICyanTemplate` interface:

## Cyan Object

The main object passed to templates, providing access to all SDK functionality.

### Properties

| Property | Type | Description |
| -------- | ---- | ----------- |
| `answers` | `Answers` | User-provided answers |
| `config` | `Config` | Template configuration |
| `inquirer` | `Inquirer` | User interaction methods |
| `determinism` | `Determinism` | Deterministic random generation |
| `files` | `FileHelper` | File operations |
| `processors` | `ProcessorRunner` | Processor execution |
| `plugins` | `PluginManager` | Plugin access |
| `children` | `ChildRunner` | Child template execution |
| `logger` | `Logger` | Logging utilities |

## Answers

Access to user answers from inquirer questions.

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface Answers {
  // Direct property access
  [key: string]: any;

  // Get answer or undefined
  get<T>(key: string): T | undefined;

  // Get answer or default
  getOrDefault<T>(key: string, defaultValue: T): T;

  // Check if answer exists
  has(key: string): boolean;

  // Get or prompt for answer
  getOrPrompt(key: string, options: TextOptions): Promise<string>;
  getOrPromptSelect(key: string, options: SelectOptions): Promise<string>;
  getOrPromptCheckbox(key: string, options: CheckboxOptions): Promise<string[]>;

  // Set answer
  set(key: string, value: any): void;
}
```

  </Tab>
  <Tab value=".NET">

```csharp
public class Answers
{
    // Indexer access
    public object this[string key] { get; set; }

    // Get typed value
    public T Get<T>(string key);

    // Get or default
    public T GetOrDefault<T>(string key, T defaultValue);

    // Check existence
    public bool Has(string key);

    // Get or prompt
    public Task<string> GetOrPromptAsync(string key, TextOptions options);
    public Task<string> GetOrPromptSelectAsync(string key, SelectOptions options);
    public Task<string[]> GetOrPromptCheckboxAsync(string key, CheckboxOptions options);

    // Set value
    public void Set(string key, object value);
}
```

  </Tab>
  <Tab value="Python">

```python
class Answers:
    # Dictionary-like access
    def __getitem__(self, key: str) -> Any: ...
    def __setitem__(self, key: str, value: Any) -> None: ...

    # Get with optional default
    def get(self, key: str, default: Any = None) -> Any: ...

    # Check existence
    def has(self, key: str) -> bool: ...

    # Get or prompt
    async def get_or_prompt(self, key: str, options: dict) -> str: ...
    async def get_or_prompt_select(self, key: str, options: dict) -> str: ...
    async def get_or_prompt_checkbox(self, key: str, options: dict) -> List[str]: ...
```

## Inquirer

User interaction methods. See [Inquirer Methods](./04-inquirer-methods) for detailed options.

### Methods

| Method | Return Type | Description |
| ------ | ----------- | ----------- |
| `text(options)` | `Promise<string>` | Text input |
| `select(options)` | `Promise<string>` | Single selection |
| `checkbox(options)` | `Promise<string[]>` | Multiple selections |
| `confirm(options)` | `Promise<boolean>` | Yes/No confirmation |
| `password(options)` | `Promise<string>` | Masked input |
| `date(options)` | `Promise<Date>` | Date picker |
| `number(options)` | `Promise<number>` | Numeric input |
| `expand(options)` | `Promise<any>` | Expandable selection |

## Determinism

Deterministic random generation for reproducible outputs.

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface Determinism {
  // Generate UUID
  uuid(): string;

  // Random float 0-1
  random(): number;

  // Random integer in range (inclusive)
  randomInt(min: number, max: number): number;

  // Random string of specified length
  randomString(length: number): string;

  // Shuffle array deterministically
  shuffle<T>(array: T[]): T[];

  // Pick random element
  pick<T>(array: T[]): T;

  // Boolean with probability
  chance(probability: number): boolean;
}
```

  </Tab>
  <Tab value=".NET">

```csharp
public class Determinism
{

    // Random string of specified length
    public string RandomString(int length);

    // Shuffle array deterministically
    public T[] Shuffle<T>(T[] array);

    // Pick random element
    public T Pick<T>(T[] array);

    // Boolean with probability
    public bool Chance(double probability);
}
```

## Glob

File pattern matching.

### Methods

<Tabs groupId="sdk-language" items={['TypeScript', '.NET', 'Python']} persist>
  <Tab value="TypeScript">

```ts
interface Cyan {
  // Single pattern
  glob(pattern: string): string[];

  // Multiple patterns (includes and excludes)
  glob(patterns: string[]): string[];

  // With options
  glob(pattern: string, options: GlobOptions): string[];
}

interface GlobOptions {
  cwd?: string;           // Base directory
  dot?: boolean;          // Include dot files
  absolute?: boolean;     // Return absolute paths
  onlyFiles?: boolean;    // Only files, not directories
  onlyDirectories?: boolean; // Only directories
}
```

  </Tab>
  <Tab value=".NET">

```csharp
public class Cyan
{
    // Single pattern
    public string[] Glob(string pattern);

    // Multiple patterns
    public string[] Glob(string[] patterns);

    // With options
    public string[] Glob(string pattern, GlobOptions options);
}

public class GlobOptions
{
    public string Cwd { get; set; }           // Base directory
    public bool Dot { get; set; }             // Include dot files
    public bool Absolute { get; set; }        // Return absolute paths
    public bool OnlyFiles { get; set; }       // Only files
    public bool OnlyDirectories { get; set; } // Only directories
}
```
