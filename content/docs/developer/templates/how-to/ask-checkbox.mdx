# How to Ask Checkbox Questions

Checkbox questions allow users to select multiple options from a predefined list. Use checkboxes when users need to select one or more features, configurations, or options.

This guide shows how to create checkbox questions using both shorthand and object forms, with examples for validation and conditional logic.

## Shorthand Form

```ts -c
const features = await i.checkbox(
  'Select features',           // Message
  ['ESLint', 'Prettier', 'Jest', 'Docker'],  // Options
  'project.features',          // Key
  'Choose features to include' // Description
);
// Returns: string[] - e.g., ['ESLint', 'Jest']
```

## Object Form (with options)

```ts -c
const features = await i.checkbox({
  type: QuestionType.Checkbox,
  id: 'project.features',
  message: 'Select features',
  desc: 'Choose features to include',
  options: ['ESLint', 'Prettier', 'Jest', 'Docker'],
  default: ['ESLint'],           // Pre-selected options
  validate: (selected) => {
    if (selected.length === 0) return 'Select at least one feature';
    return null;
  }
});
```

## Using Results

### In Template Logic

```ts -c
const features = await i.checkbox(
  'Select features',
  ['ESLint', 'Prettier', 'Jest'],
  'project.features',
  'Choose features'
);

// Check if specific feature is selected
const hasEslint = features.includes('ESLint');
const hasJest = features.includes('Jest');

// Use in config
config: {
  vars: {
    features: features.join(', '),  // "ESLint, Jest"
    hasEslint: hasEslint ? 'true' : 'false',
    hasJest: hasJest ? 'true' : 'false'
  }
}
```

### Conditional Files Based on Selection

```ts -c
const features = await i.checkbox(
  'Select features',
  ['ESLint', 'Prettier', 'Jest'],
  'project.features',
  'Choose features'
);

const files = [
  { root: 'templates/base', glob: '**/*', exclude: [], type: GlobType.Template }
];

if (features.includes('ESLint')) {
  files.push({ root: 'templates/eslint', glob: '**/*', exclude: [], type: GlobType.Copy });
}

if (features.includes('Jest')) {
  files.push({ root: 'templates/jest', glob: '**/*', exclude: [], type: GlobType.Copy });
}
```

## Common Patterns

### With Validation

```ts -c
const databases = await i.checkbox({
  type: QuestionType.Checkbox,
  id: 'project.databases',
  message: 'Select databases',
  desc: 'Choose database support',
  options: ['PostgreSQL', 'MySQL', 'MongoDB', 'Redis'],
  validate: (selected) => {
    if (selected.length > 2) {
      return 'Maximum 2 databases supported';
    }
    return null;
  }
});
```

### With Defaults

```ts -c
const features = await i.checkbox({
  type: QuestionType.Checkbox,
  id: 'project.features',
  message: 'Select features',
  desc: 'Choose features',
  options: ['ESLint', 'Prettier', 'Jest', 'Docker'],
  default: ['ESLint', 'Prettier']  // Pre-selected
});
```
