# How to Ask Confirm Questions

Use confirm questions for boolean yes/no choices.

## Shorthand Form

```ts template.ts -c
const useTypescript = await i.confirm(
  'Use TypeScript?',     // Message
  'project.typescript',  // Key
  'Add TypeScript config' // Description
);
```

## Object Form (with default)

```ts template.ts -c
const useTypescript = await i.confirm({
  type: QuestionType.Confirm,
  id: 'project.typescript',
  message: 'Use TypeScript?',
  desc: 'Add TypeScript configuration',
  default: true  // Default to yes
});
```

<Callout type="info">
The `confirm` method returns a `boolean` - `true` for yes, `false` for no.
</Callout>

## Using Results

### In Template Logic

```ts processor.ts -c
const docker = await i.confirm('Add Docker?', 'project.docker', 'Include Docker support');

// Use directly in conditionals
if (docker) {
  files.push({ root: 'templates/docker', glob: '**/*', exclude: [], type: GlobType.Template });
}

// Convert to string for template vars
config: {
  vars: {
    hasDocker: docker ? 'yes' : 'no',
    docker: docker ? 'true' : 'false'
  }
}
```

### Multiple Related Confirms

```ts processor.ts -c
const typescript = await i.confirm('Use TypeScript?', 'project.typescript', 'Add TS config');
const eslint = await i.confirm('Add ESLint?', 'project.eslint', 'Add ESLint config');
const prettier = await i.confirm('Add Prettier?', 'project.prettier', 'Add Prettier config');
const docker = await i.confirm('Add Docker?', 'project.docker', 'Add Docker support');

return {
  processors: [{
    name: 'cyan/default',
    files: [
      { root: 'templates/base', glob: '**/*', exclude: [], type: GlobType.Template },
      ...(typescript ? [{ root: 'templates/typescript', glob: '**/*', exclude: [], type: GlobType.Template }] : []),
      ...(eslint ? [{ root: 'templates/eslint', glob: '**/*', exclude: [], type: GlobType.Copy }] : []),
      ...(docker ? [{ root: 'templates/docker', glob: '**/*', exclude: [], type: GlobType.Template }] : [])
    ],
    config: {
      vars: {
        typescript: typescript ? 'true' : 'false',
        eslint: eslint ? 'true' : 'false',
        docker: docker ? 'true' : 'false'
      }
    }
  }]
};
```

## Common Patterns

### Conditional Questions

Ask follow-up questions based on confirm response:

```ts conditional.ts -c
const useDatabase = await i.confirm('Use a database?', 'project.db', 'Add database config');

let dbType = null;
if (useDatabase) {
  dbType = await i.select(
    'Which database?',
    ['PostgreSQL', 'MySQL', 'MongoDB'],
    'project.db.type',
    'Choose database'
  );
}
```

### With Default True

```ts default-true.ts -c
// Default to yes for common choices
const addReadme = await i.confirm({
  type: QuestionType.Confirm,
  id: 'project.readme',
  message: 'Add README?',
  desc: 'Include README.md',
  default: true
});
```
