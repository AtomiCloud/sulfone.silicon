# How to Ask Confirm Questions

Use confirm questions for boolean yes/no choices.

## Shorthand Form

<Tabs items={['TypeScript', 'Python', 'C#']}>
  <Tab value="TypeScript">
    ```ts
    const useTypescript = await i.confirm(
      'Use TypeScript?',      // !callout[/'Use TypeScript?'/] Message shown to user
      'project.typescript',   // !callout[/'project.typescript'/] Unique key for this answer
      'Add TypeScript config' // !callout[/'Add TypeScript config'/] Description shown in UI
    );
    ```
  </Tab>

  <Tab value="Python">
    ```python
    use_typescript = await i.confirm(
      'Use TypeScript?',      # !callout[/'Use TypeScript?'/] Message shown to user
      'project.typescript',   # !callout[/'project.typescript'/] Unique key for this answer
      'Add TypeScript config' # !callout[/'Add TypeScript config'/] Description shown in UI
    )
    ```
  </Tab>

  <Tab value="C#">
    ```csharp
    var useTypescript = await i.Confirm(
      "Use TypeScript?",      // !callout[/"Use TypeScript?"/] Message shown to user
      "project.typescript",   // !callout[/"project.typescript"/] Unique key for this answer
      "Add TypeScript config" // !callout[/"Add TypeScript config"/] Description shown in UI
    );
    ```
  </Tab>
</Tabs>

## Object Form (with Default)

<Tabs items={['TypeScript', 'Python', 'C#']}>
  <Tab value="TypeScript">
    ```ts
    const useTypescript = await i.confirm({
      type: QuestionType.Confirm,
      id: 'project.typescript',
      message: 'Use TypeScript?',
      desc: 'Add TypeScript configuration',
      default: true  // !callout[/default: true/] Pre-selects "yes"
    });
    ```
  </Tab>

  <Tab value="Python">
    ```python
    use_typescript = await i.confirm(
      type=QuestionType.Confirm,
      id='project.typescript',
      message='Use TypeScript?',
      desc='Add TypeScript configuration',
      default=True  # !callout[/default=True/] Pre-selects "yes"
    )
    ```
  </Tab>

  <Tab value="C#">
    ```csharp
    var useTypescript = await i.Confirm(
        type: QuestionType.Confirm,
        id: "project.typescript",
        message: "Use TypeScript?",
        desc: "Add TypeScript configuration",
        default: true  // !callout[/default: true/] Pre-selects "yes"
    );
    ```
  </Tab>
</Tabs>

<Callout type="info">
The `confirm` method returns a `boolean` - `true` for yes, `false` for no.
</Callout>

## Using Results

<Tabs items={['TypeScript', 'Python', 'C#']}>
  <Tab value="TypeScript">
    ```ts
    const docker = await i.confirm('Add Docker?', 'project.docker', 'Include Docker support');

    if (docker) {  // !mark
      files.push({ root: 'templates/docker', glob: '**/*', exclude: [], type: GlobType.Template });
    }

    config: {
      vars: {
        hasDocker: docker ? 'yes' : 'no'  // !mark
      }
    }
    ```
  </Tab>

  <Tab value="Python">
    ```python
    docker = await i.confirm('Add Docker?', 'project.docker', 'Include Docker support')

    if docker:  # !mark
        files.append({'root': 'templates/docker', 'glob': '**/*', 'exclude': [], 'type': GlobType.Template})

    'config': {
        'vars': {
            'hasDocker': 'yes' if docker else 'no'  # !mark
        }
    }
    ```
  </Tab>

  <Tab value="C#">
    ```csharp
    var docker = await i.Confirm("Add Docker?", "project.docker", "Include Docker support");

    if (docker)  // !mark
    {
        files.Add(new { root = "templates/docker", glob = "**/*", exclude = Array.Empty<string>(), type = GlobType.Template });
    }

    config = new {
        vars = new {
            hasDocker = docker ? "yes" : "no"  // !mark
        }
    };
    ```
  </Tab>
</Tabs>
