# How to Ask Password Questions

Use password questions for sensitive input that should be hidden from display.

## Shorthand Form

```ts
const apiKey = await i.password(
  'Enter API key',    // Message
  'secrets.apiKey',   // Key
  'Your API key'      // Description
);
// Returns: string (hidden input)
```

## Object Form

```ts
const apiKey = await i.password({
  type: QuestionType.Password,
  id: 'secrets.apiKey',
  message: 'Enter API key',
  desc: 'Your secret API key',
  validate: (input) => {
    if (!input) return 'API key is required';
    if (input.length < 20) return 'API key seems too short';
    return null;
  }
});
```

## Security Considerations

<Callout type="warn">
Passwords and secrets should never be stored in template output files. Use them only for runtime configuration or external services.
</Callout>

### Safe Patterns

```ts
const dbPassword = await i.password('Database password?', 'secrets.dbPassword', 'Enter password');

// Good: Use for environment file (should be gitignored)
config: {
  vars: {
    // Template will create .env.example with placeholder
    envExampleContent: `DATABASE_URL=postgresql://user:YOUR_PASSWORD@localhost/db`
  }
}

// Never do this:
config: {
  vars: {
    // BAD: Password in committed file
    dbPassword: dbPassword
  }
}
```

### Environment File Pattern

Create `.env.example` with placeholders:

```ts
const dbPassword = await i.password('DB password?', 'secrets.db', 'Enter password');
const apiKey = await i.password('API key?', 'secrets.api', 'Enter key');

return {
  processors: [{
    name: 'cyan/default',
    files: [
      { root: 'templates', glob: '**/*', exclude: ['.env'], type: GlobType.Template }
    ],
    config: {
      vars: {
        // For .env.example (committed to git)
        envExampleContent: `DATABASE_URL=postgresql://user:password@localhost/db
API_KEY=your-api-key-here`
      }
    }
  }]
};
```

## Using with External Services

```ts
const npmToken = await i.password('NPM token?', 'secrets.npm', 'For publishing packages');

// Configure .npmrc (should be gitignored)
config: {
  vars: {
    npmrcContent: `//registry.npmjs.org/:_authToken=${npmToken}`
  }
}
```

## Validation Patterns

```ts
const password = await i.password({
  type: QuestionType.Password,
  id: 'secrets.password',
  message: 'Enter password',
  desc: 'Choose a strong password',
  validate: (input) => {
    if (input.length < 8) return 'Password must be at least 8 characters';
    if (!/[A-Z]/.test(input)) return 'Include at least one uppercase letter';
    if (!/[0-9]/.test(input)) return 'Include at least one number';
    return null;
  }
});
```
