# How to Set Default Values

Default values improve user experience by providing sensible starting points.

## Shorthand vs Object Form

Shorthand forms don't support defaults. Use the object form for default values:

```ts
// Shorthand - no default support
const name = await i.text('Name?', 'project.name', 'Enter name');

// Object form - supports default
const name = await i.text({
  type: QuestionType.Text,
  id: 'project.name',
  message: 'Name?',
  desc: 'Enter project name',
  default: 'my-project'  // Default value
});
```

## Default by Question Type

### Text

```ts
const name = await i.text({
  type: QuestionType.Text,
  id: 'project.name',
  message: 'Project name?',
  desc: 'Enter name',
  default: 'my-project'
});
```

### Select

```ts
const license = await i.select({
  type: QuestionType.Select,
  id: 'project.license',
  message: 'License?',
  desc: 'Choose license',
  options: ['MIT', 'Apache-2.0', 'GPL-3.0'],
  default: 'MIT'  // Must match an option
});
```

### Confirm

```ts
const typescript = await i.confirm({
  type: QuestionType.Confirm,
  id: 'project.typescript',
  message: 'Use TypeScript?',
  desc: 'Add TypeScript config',
  default: true  // true or false
});
```

### Checkbox

```ts
const features = await i.checkbox({
  type: QuestionType.Checkbox,
  id: 'project.features',
  message: 'Features?',
  desc: 'Select features',
  options: ['ESLint', 'Prettier', 'Jest', 'Docker'],
  default: ['ESLint', 'Prettier']  // Array of pre-selected options
});
```

### Date

```ts
const startDate = await i.dateSelect({
  type: QuestionType.DateSelect,
  id: 'project.start',
  message: 'Start date?',
  desc: 'Project start',
  default: new Date()  // Date object
});
```

## Computed Defaults

Calculate defaults dynamically:

```ts
const projectName = await i.text({
  type: QuestionType.Text,
  id: 'project.name',
  message: 'Project name?',
  desc: 'Enter name',
  default: process.cwd().split('/').pop() || 'my-project'  // Current directory name
});
```

```ts
// Default to one month from now
const defaultDeadline = new Date();
defaultDeadline.setMonth(defaultDeadline.getMonth() + 1);

const deadline = await i.dateSelect({
  type: QuestionType.DateSelect,
  id: 'project.deadline',
  message: 'Deadline?',
  desc: 'Target date',
  default: defaultDeadline
});
```

## Conditional Defaults

Set defaults based on previous answers:

```ts
const framework = await i.select({
  type: QuestionType.Select,
  id: 'project.framework',
  message: 'Framework?',
  desc: 'Choose framework',
  options: ['React', 'Vue', 'Svelte'],
  default: 'React'
});

// Default test framework based on main framework
const testFramework = await i.select({
  type: QuestionType.Select,
  id: 'project.testing',
  message: 'Test framework?',
  desc: 'Choose testing tool',
  options: ['Jest', 'Vitest', 'Mocha'],
  default: framework === 'Vue' ? 'Vitest' : 'Jest'  // Conditional default
});
```

## Best Practices

1. **Be opinionated** - Provide sensible defaults for common choices
2. **Document defaults** - Make it clear what the default is
3. **Consider context** - Defaults should match the project type
4. **Allow override** - Users should always be able to change the default
