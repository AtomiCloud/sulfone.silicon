# SDK Overview

The CyanPrint SDK (`@atomicloud/cyan-sdk`) provides the APIs for creating templates, processors, and plugins.

## Installation

```bash
npm install @atomicloud/cyan-sdk
```

## Core Exports

### Entry Points

| Export | Purpose |
|--------|---------|
| `StartTemplateWithLambda` | Entry point for templates |
| `StartProcessorWithLambda` | Entry point for processors |
| `StartPluginWithLambda` | Entry point for plugins |

### Interfaces

| Interface | Description |
|-----------|-------------|
| `IInquirer` | Ask user questions |
| `IDefine` | Generate deterministic values |
| `ICyanConfig` | Template configuration structure |
| `IProcessor` | Processor definition |

### Types

| Type | Description |
|------|-------------|
| `GlobType` | File processing types |
| `QuestionType` | Question type enum |
| `FileGroup` | File group configuration |

## Quick Start

### Template Entry Point

```ts
import { StartTemplateWithLambda, GlobType } from '@atomicloud/cyan-sdk';

StartTemplateWithLambda(async (i, d) => {
  // i: IInquirer - ask questions
  // d: IDefine - get deterministic values

  return {
    processors: [{
      name: 'cyan/default',
      files: [{ root: 'templates', glob: '**/*', exclude: [], type: GlobType.Template }],
      config: { vars: {} }
    }]
  };
});
```

### Using IInquirer

```ts
// Text input
const name = await i.text('Project name?', 'project.name', 'Enter name');

// Selection
const license = await i.select('License?', ['MIT', 'Apache-2.0'], 'project.license', 'Choose');

// Confirmation
const typescript = await i.confirm('Use TypeScript?', 'project.typescript', 'Add TS config');

// Checkbox (multi-select)
const features = await i.checkbox('Features?', ['ESLint', 'Prettier'], 'project.features', 'Select');
```

### Using IDefine

```ts
// Deterministic UUID
const projectId = d.uuid();

// Deterministic timestamp
const createdAt = d.timestamp();

// Sequential numbers
const userId = d.seq('users');
```
