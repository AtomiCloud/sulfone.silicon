# Tutorial 1: Blank Template

Create a template from scratch and test it immediately using the `try` command. This is the starting point for all template development.

## Prerequisites

- Docker installed and running
- CyanPrint CLI installed
- Runtime requirements (choose one):
  - **TypeScript**: Node.js 18+ and Bun
  - **Python**: Python 3.11+ and pip
  - **C#**: .NET 8 SDK

## Create Project

<Steps>

### Create Directory Structure

```bash -c
mkdir my-first-template
cd my-first-template
mkdir -p cyan templates
```

### Create cyan.yaml

Create `cyan.yaml` with template metadata:

```yaml cyan.yaml -c
username: myuser
name: my-first-template
description: My first CyanPrint template
project: https://github.com/myuser/my-first-template
source: https://github.com/myuser/my-first-template
email: myuser@example.com
tags: []
readme: README.md

build:
  registry: docker.io
  images:
    blob:
      image: myuser/my-first-template-blob
      dockerfile: cyan/Dockerfile
      context: .
    template:
      image: myuser/my-first-template
      dockerfile: cyan/template.Dockerfile
      context: .
```

### Create Template Files

Create your template content:

```bash -c
echo "# My Project" > templates/README.md
echo "node_modules/" > templates/.gitignore
```

</Steps>

## Create Template Logic

<Tabs items={['TypeScript', 'Python', 'C#']} persist groupId="runtime">
<Tab value="TypeScript">

Create `cyan/index.ts`:

```ts cyan/index.ts -c
import { StartTemplateWithLambda, GlobType } from '@atomicloud/cyan-sdk';

StartTemplateWithLambda(async (i, d) => {
  // !callout[/StartTemplateWithLambda/] Entry point - starts the template server on port 5550
  const name = await i.text('What is your project name?', 'myuser/my-first-template/name');

  return {
    processors: [{
      name: 'cyan/default',
      files: [{ root: 'templates', glob: '**/*', exclude: [], type: GlobType.Copy }],
      config: { vars: { name } }
    }]
  };
});
```

Create `cyan/package.json`:

```json cyan/package.json -c
{
  "name": "my-first-template",
  "version": "1.0.0",
  "type": "module",
  "dependencies": {
    "@atomicloud/cyan-sdk": "latest"
  }
}
```

Create `cyan/Dockerfile`:

```dockerfile cyan/Dockerfile -c
FROM oven/bun:1.1.31

WORKDIR /app

LABEL cyanprint.dev=true

COPY package.json bun.lockb* ./

COPY . .

CMD ["bun", "run", "index.ts"]
```

Create `cyan/template.Dockerfile`:


<Tab value="Python">

Create `cyan/index.py`:

```python cyan/index.py -c
from cyanprintsdk import start_template_with_fn, GlobType
from cyanprintsdk.domain.core.cyan import Cyan, CyanProcessor, CyanGlob

async def my_template(i, d):
    # !callout[/start_template_with_fn/] Entry point - starts the template server on port 5550
    name = await i.text("What is your project name?", "myuser/my-first-template/name")

    return Cyan(
        processors=[
            CyanProcessor(
                name="cyan/default",
                files=[
                    CyanGlob(
                        root="templates",
                        glob="**/*",
                        exclude=[],
                        type=GlobType.Copy
                    )
                ],
                config={"vars": {"name": name}}
            )
        ]
    )

start_template_with_fn(my_template)
```

Create `cyan/requirements.txt`:

```text cyan/requirements.txt -c
cyanprintsdk>=1.0.0
```

Create `cyan/Dockerfile`:

<Tab value="C#">

Create `cyan/Program.cs`:

```csharp cyan/Program.cs -c
using sulfone_helium;
using sulfone_helium.Domain.Core;

CyanEngine.StartTemplate(args, async (i, d) =>
{
    // !callout[/StartTemplate/] Entry point - starts the template server on port 5550
    var name = await i.Text("What is your project name?", "myuser/my-first-template/name");

    return new Cyan
    {
        Processors =
        [
            new CyanProcessor
            {
                Name = "cyan/default",
                Files =
                [
                    new CyanGlob
                    {
                        Root = "templates",
                        Glob = "**/*",
                        Exclude = [],
                        Type = GlobType.Copy
                    }
                ],
                Config = new { vars = new { name } }
            }
        ]
    };
});
```

## Test Your Template

### Run the Try Command

```bash -c
cyanprint try template . ./test-output
```

This command will:
1. Build the template Docker image automatically
2. Start the coordinator daemon
3. Prompt for your template questions
4. Generate the project to `./test-output`

### Check the Output

```bash -c
ls ./test-output
cat ./test-output/README.md
```

<Callout type="info">
The try command automatically builds Docker images—you don't need to run `docker build` manually. This provides a fast development loop: write code, test, iterate.
</Callout>

### GlobType.Copy

The `GlobType.Copy` copies files without any variable substitution—perfect for static files that don't need processing.

## Development Workflow

### Iterate Quickly

```bash -c
# Make changes to your template...

# Test again
rm -rf ./test-output
cyanprint try template . ./test-output
```

### Keep Containers for Debugging

```bash -c
cyanprint try template . ./test-output --keep-containers
```

## Automated Testing

Once your template works with `try`, set up automated snapshot tests:

```bash -c
# Generate test cases from your template's Q&A tree
cyanprint test init .
```

This creates `test.cyan.yaml` and `fixtures/expected/` with snapshot test cases. Run them anytime:

```bash -c
cyanprint test template .
```

<Callout type="info">
Automated tests verify your template produces consistent output across changes. See [Automated Testing](/docs/developer/templates/how-to/automated-testing) for the full guide.
</Callout>
