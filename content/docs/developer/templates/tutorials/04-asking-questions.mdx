# Tutorial 4: Asking Questions

Collect user input to customize the generated project. Questions make templates interactive and reusable.

## The IInquirer Interface

The `i` parameter provides methods to ask different question types:

```ts
StartTemplateWithLambda(async (i, d) => {
  // i is the IInquirer interface
  const name = await i.text('Project name?', 'project.name', 'Enter name');
  // ...
});
```

## Adding Questions

Combine multiple question types for a rich setup experience:

```ts
import { StartTemplateWithLambda, GlobType } from '@atomicloud/cyan-sdk';

StartTemplateWithLambda(async (i, d) => {
  // Text input
  const name = await i.text('Project name?', 'project.name', 'Enter project name');

  // Single select
  const license = await i.select(
    'License?',
    ['MIT', 'Apache-2.0', 'GPL-3.0'],
    'project.license',
    'Choose license'
  );

  // Boolean confirmation
  const docker = await i.confirm('Add Docker?', 'project.docker', 'Include Dockerfile');

  // Multi-select
  const features = await i.checkbox(
    'Features?',
    ['TypeScript', 'ESLint', 'Prettier', 'Testing'],
    'project.features',
    'Select features'
  );

  return {
    processors: [{
      name: 'cyan/default',
      files: [{ root: 'templates', glob: '**/*', exclude: [], type: GlobType.Template }],
      config: {
        vars: {
          name,
          license,
          docker,
          features: features.join(', ')
        }
      }
    }]
  };
});
```

## Question Types

| Method | Returns | Example Use |
|--------|---------|-------------|
| `text()` | `string` | Project name, author |
| `select()` | `string` | License, framework choice |
| `confirm()` | `boolean` | Yes/no decisions |
| `checkbox()` | `string[]` | Feature selection |
| `password()` | `string` | Secrets, API keys |
| `dateSelect()` | `string` | Dates, deadlines |

## Keys Concept

The `id` parameter (second argument) is the **key**. Keys enable answer reuse:

```ts
// Both questions get the same answer!
const name1 = await i.text('Project name?', 'name', '...');
const name2 = await i.text('Confirm name?', 'name', '...');
// name1 === name2 (same key = same answer)
```

### Namespacing Your Keys

<Callout type="warn">
Always namespace your keys to prevent collisions when templates are composed.
</Callout>

```ts
// Good: namespaced keys
const name = await i.text('Project name?', 'my-template.project.name', '...');
const version = await i.text('Version?', 'my-template.project.version', '...');

// Bad: generic keys that might collide
const name = await i.text('Project name?', 'name', '...');
```

### Why Namespacing Matters

When users compose multiple templates, non-namespaced keys can cause conflicts:

```ts
// Template A
const name = await i.text('Name?', 'name', '...');

// Template B (composed with A)
const name = await i.text('Name?', 'name', '...'); // Gets A's answer!
```

With namespacing:

```ts
// Template A
const name = await i.text('Name?', 'template-a.name', '...');

// Template B (composed with A)
const name = await i.text('Name?', 'template-b.name', '...'); // Independent answer
```

## Using Answers in Templates

Pass collected answers to processor config:

```ts
config: {
  vars: {
    name,                    // Project name
    license,                 // Selected license
    docker: docker ? 'yes' : 'no',  // Conditional value
    features: features.join(', ')   // Array to string
  }
}
```

Use in template files:

```markdown
# var__name__

## License

This project is licensed under the **var__license__** license.

## Features

This project includes: var__features__
```

## Conditional Templates

Use boolean answers for conditional content:

```ts
config: {
  vars: {
    name,
    hasDocker: docker ? 'true' : 'false'
  }
}
```

## Complete Example

```ts
import { StartTemplateWithLambda, GlobType } from '@atomicloud/cyan-sdk';

StartTemplateWithLambda(async (i, d) => {
  // Collect all user input
  const name = await i.text('Project name?', 'my-template.name', 'Enter name');
  const description = await i.text('Description?', 'my-template.desc', 'Brief description');
  const license = await i.select('License?', ['MIT', 'Apache-2.0'], 'my-template.license', 'Choose');
  const typescript = await i.confirm('TypeScript?', 'my-template.typescript', 'Use TypeScript');
  const features = await i.checkbox(
    'Features?',
    ['ESLint', 'Prettier', 'Testing', 'CI/CD'],
    'my-template.features',
    'Select'
  );

  return {
    processors: [{
      name: 'cyan/default',
      files: [
        { root: 'templates', glob: '**/*.md', exclude: [], type: GlobType.Template },
        { root: 'templates', glob: '**/*.json', exclude: [], type: GlobType.Template },
        { root: 'templates', glob: '**/*.ts', exclude: [], type: GlobType.Template },
        { root: 'templates', glob: '**/*.png', exclude: [], type: GlobType.Copy }
      ],
      config: {
        vars: {
          name,
          description,
          license,
          typescript: typescript ? 'true' : 'false',
          features: features.join(', ')
        }
      }
    }]
  };
});
```
