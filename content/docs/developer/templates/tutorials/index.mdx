# Template Tutorials

Learn template development step by step with these progressive tutorials.

## Learning Path

Follow the tutorials in order to build your understanding:

### 1. [Blank Template](/developer/templates/tutorials/01-blank-template)

Create your first template using the meta template. Learn the basic structure and how templates work.

**What you'll learn:**
- Creating a template project
- Basic template structure
- Using `GlobType.Copy`

### 2. [Adding Variables](/developer/templates/tutorials/02-adding-variables)

Add variable substitution to your templates using the default processor.

**What you'll learn:**
- Using `GlobType.Template`
- Variable syntax (`var__name__`)
- Passing variables to templates

### 3. [Changing Glob Patterns](/developer/templates/tutorials/03-changing-glob)

Control which files are processed versus copied as-is.

**What you'll learn:**
- Multiple file groups
- Exclude patterns
- Handling binary files

### 4. [Asking Questions](/developer/templates/tutorials/04-asking-questions)

Collect user input to customize generated projects.

**What you'll learn:**
- Inquirer interface
- Question types
- Keys and namespacing

### 5. [Full Example](/developer/templates/tutorials/full-example)

A complete template demonstrating all features together.

**What you'll learn:**
- Putting it all together
- Conditional file inclusion
- Plugin integration

## Prerequisites

Before starting the tutorials, ensure you have:

- Docker installed and running
- CyanPrint CLI installed
- Node.js 18+ for local development
- Basic TypeScript knowledge
