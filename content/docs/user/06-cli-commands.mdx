# CLI Commands

This page provides a comprehensive reference for all CyanPrint CLI (Iridium) commands.

## Global Options

These options are available for all commands:

| Option              | Description                              |
| ------------------- | ---------------------------------------- |
| `-h, --help`        | Show help for any command                |
| `-V, --version`     | Show CLI version                         |
| `-v, --verbose`     | Enable verbose output                    |
| `-q, --quiet`       | Suppress non-essential output            |
| `--no-color`        | Disable colored output                   |
| `--config <path>`   | Use custom config file                   |

## Core Commands

### cyanprint init

Initialize a new project from a template.

```bash
cyanprint init [name] [options]
```

#### Arguments

| Argument | Description                              | Default     |
| -------- | ---------------------------------------- | ----------- |
| `name`   | Project directory name                   | Current dir |

#### Options

| Option                    | Description                              |
| ------------------------- | ---------------------------------------- |
| `-t, --template <name>`   | Template to use                          |
| `-v, --template-version <version>` | Specific template version      |
| `-d, --directory <path>`  | Output directory                         |
| `-o, --overwrite`         | Overwrite existing files                 |
| `--dry-run`               | Preview without creating files           |
| `--no-cache`              | Disable template caching                 |
| `--offline`               | Use cached templates only                |

#### Examples

```bash
# Interactive template selection
cyanprint init my-project

# Specify template
cyanprint init my-project --template nextjs-dashboard

# Use specific version
cyanprint init my-project -t nextjs-dashboard -v 2.0.0

# Preview without creating files
cyanprint init my-project -t react-starter --dry-run

# Create in current directory
cyanprint init . -t express-api
```

### cyanprint search

Search for templates in the registry.

```bash
cyanprint search [query] [options]
```

#### Arguments

| Argument | Description                              |
| -------- | ---------------------------------------- |
| `query`  | Search query (name, keywords, etc.)      |

#### Options

| Option                  | Description                              |
| ----------------------- | ---------------------------------------- |
| `-l, --language <lang>` | Filter by programming language           |
| `--tag <tag>`           | Filter by tag (can be used multiple times)|
| `--org <org>`           | Filter by organization                   |
| `--private`             | Include private templates                |
| `--limit <n>`           | Limit number of results                  |
| `--json`                | Output as JSON                           |

#### Examples

```bash
# Search by name/keyword
cyanprint search react

# Filter by language
cyanprint search --language typescript

# Filter by tags
cyanprint search --tag backend --tag api

# Organization templates
cyanprint search --org mycompany

# JSON output
cyanprint search react --json
```


#### Arguments

| Argument    | Description                              |
| ----------- | ---------------------------------------- |
| `template`  | Template name to show details for        |

#### Options

| Option              | Description                              |
| ------------------- | ---------------------------------------- |
| `-v, --version <v>` | Show specific version                    |
| `--readme`          | Display the template's README            |

## Update Commands

### cyanprint update

Update the CLI or project template.

```bash
cyanprint update [options]
```

#### Options

| Option              | Description                              |
| ------------------- | ---------------------------------------- |
| `--self`            | Update the CLI itself                    |
| `--template`        | Update project's template                |
| `--list`            | List files with available updates        |
| `--files <...>`     | Update specific files only               |
| `--continue`        | Continue after resolving conflicts       |
| `--abort`           | Abort update and restore backup          |

#### Examples

```bash
# Update CLI to latest version
cyanprint update --self

# Update project template
cyanprint update --template

# List available updates
cyanprint update --list

# Update specific files
cyanprint update --files tsconfig.json package.json

# Continue after conflicts
cyanprint update --continue
```

| Option              | Description                              |

## Configuration Commands

### cyanprint config

Manage CLI configuration.

```bash
cyanprint config <command> [options]
```

#### Subcommands

| Subcommand            | Description                              |
| --------------------- | ---------------------------------------- |
| `list`                | List all configuration values            |
| `get <key>`           | Get a specific configuration value       |
| `set <key> <value>`   | Set a configuration value                |
| `unset <key>`         | Remove a configuration value             |

#### Common Configuration Keys

| Key                   | Description                              | Default                  |
| --------------------- | ---------------------------------------- | ------------------------ |
| `registry`            | Default registry URL                     | https://registry.cyanprint.dev |
| `cache.dir`           | Template cache directory                 | `~/.cyanprint/cache`     |
| `cache.ttl`           | Cache time-to-live (hours)               | 24                       |
| `docker.timeout`      | Container execution timeout (seconds)    | 300                      |
| `output.color`        | Enable colored output                    | true                     |

#### Examples

```bash
# List configuration
cyanprint config list

# Set registry
cyanprint config set registry https://registry.company.com

# Get a value
cyanprint config get registry

# Unset a value
cyanprint config unset registry
```

## Environment Variables

Configure CyanPrint behavior with environment variables:

| Variable                   | Description                              |
| -------------------------- | ---------------------------------------- |
| `CYANPRINT_REGISTRY`       | Override default registry URL            |
| `CYANPRINT_CONFIG`         | Path to config file                      |
| `CYANPRINT_CACHE_DIR`      | Override cache directory                 |
| `CYANPRINT_NO_COLOR`       | Disable colored output (set to `1`)      |
| `CYANPRINT_DEBUG`          | Enable debug logging (set to `1`)        |
| `CYANPRINT_OFFLINE`        | Force offline mode (set to `1`)          |

#### Examples

```bash
# Use enterprise registry
CYANPRINT_REGISTRY=https://registry.company.com cyanprint search

# Debug mode
CYANPRINT_DEBUG=1 cyanprint init my-project

# Offline mode
CYANPRINT_OFFLINE=1 cyanprint init my-project -t cached-template
```

## Exit Codes

The CLI returns these exit codes:

| Code | Meaning                                  |
| ---- | ---------------------------------------- |
| 0    | Success                                  |
| 1    | General error                            |
| 2    | Invalid arguments                        |
| 3    | Authentication error                     |
| 4    | Network error                            |
| 5    | Template not found                       |
| 6    | Docker error                             |
| 7    | Configuration error                      |
