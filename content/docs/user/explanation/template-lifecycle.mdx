# Template Lifecycle

## Versioning

Templates use semantic versioning (MAJOR.MINOR.PATCH).

- **MAJOR**: Breaking changes
- **MINOR**: New features, backward compatible
- **PATCH**: Bug fixes

## Updates

When a template is updated, you can use the `cyanprint update` command to bring your project up to date while preserving your customizations.

See [Update a Project](/user/how-to/update-project) for the how-to guide.

## Deprecation

Templates may be deprecated by their maintainers. Deprecated templates remain available but show a warning when used.
