# Browse Templates

**Template discovery is via the web UI only.** There is no CLI search command.

Visit [cyanprint.dev/registry](https://cyanprint.dev/registry) to:

- Search by name, username, or tags
- Browse Templates, Plugins, Processors, and Resolvers
- View template details and versions
- See usage statistics

For programmatic access, you can use the [REST API](/user/reference/api) directly.
