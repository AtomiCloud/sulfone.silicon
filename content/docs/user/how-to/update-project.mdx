# Update a Project

```bash
# Update to latest versions
cyanprint update

# Interactive version selection
cyanprint update -i
```

## How Updates Work

CyanPrint uses a 3-way merge to preserve your customizations when updating. See [3-Way Merge](/user/explanation/3-way-merge) to understand how updates preserve your changes.
