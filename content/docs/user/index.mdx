# User Documentation

Welcome to the CyanPrint user documentation. This guide will help you get started with using CyanPrint to scaffold new projects from templates.

## What is CyanPrint?

CyanPrint is a template management platform that helps you create consistent, reproducible project scaffolding. Instead of copying and pasting boilerplate code or manually setting up project structures, you can use pre-built templates to generate new projects in seconds.

## Who Is This For?

This documentation is designed for:

- **Developers** who want to quickly scaffold new projects
- **Teams** looking for consistent project structures across their organization
- **Anyone** who wants to use existing templates from the registry

If you're interested in creating your own templates, see the [Developer Documentation](/docs/developer).
