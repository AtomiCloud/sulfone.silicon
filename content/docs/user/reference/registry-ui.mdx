# Registry UI Reference

The CyanPrint Registry is available at [registry.cyanprint.dev](https://registry.cyanprint.dev).

## Features

### Search

Search for templates by:

- Template name
- Author/username
- Tags

### Template Details

View detailed information about each template:

- Description and readme
- Available versions
- Usage statistics
- Author information

### Version History

Browse all available versions of a template to find the one you need.
